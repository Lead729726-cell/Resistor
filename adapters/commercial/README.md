# Install-later recipes

`catalog.json` lists seventeen commercial tool families plus explicitly open-source ngspice calibration. `templates/*.json` are concrete operator manifests with different native entry modes, formats and output roles. They are **needs-site-validation/unverified**. Missing licensed executables/resources produce unavailable checks and do not launch jobs. No commercial PDK, license, model, OA/Milkyway/NDM database or vendor script is redistributed here.

Virtuoso/strmout native exporters handle OpenAccess; ICC handles Milkyway; ICC2/Fusion Compiler handle NDM. The runner can snapshot bounded opaque operator library directories, but only a vendor/site exporter can read these formats and produce actual GDSII/OASIS or supported text. An output becomes this project's authoritative geometry only through explicit backend.import_layout.

The historical Virtuoso -nograph/-restore, Spectre input netlist/-raw, Assura RSF, Quantus -cmd and HSPICE -i/-o entries are documented in primary vendor material linked in `catalog.json.templates`. Their release/foundry behavior still needs validation. Other release candidates deliberately state that the installed vendor manual and site runset are required; a public product description does not verify a CLI version. Generated bindings supply safe data to the operator's registered site script rather than inventing proprietary APIs.

Primary examples: [Cadence Virtuoso batch entry](https://community.cadence.com/cadence_technology_forums/f/custom-ic-skill/13779/perform-skill-functions-in-command-line-mode), [Spectre standalone/raw directory](https://community.cadence.com/cadence_technology_forums/f/mixed-signal-design/32214/running-spectre-in-command-line/1340679), [Assura RSF](https://community.cadence.com/cadence_technology_forums/f/custom-ic-skill/16741/assura-drc-lvs-rcx-batch-run-with-skill), [Quantus command file](https://community.cadence.com/cadence_technology_forums/f/custom-ic-design/41124/assura-qrc-error-in-batch-mode/1358948), [Synopsys HSPICE K-2015.06 reference](https://www.synopsys.com/content/dam/synopsys/verification/datasheets/hspice_quickref_Jun2015.pdf), [Siemens xACT workflow/decks](https://blogs.sw.siemens.com/calibre/2026/02/17/how-to-use-calibre-parasitic-extraction-tools-step-by-step-guide/).

`calibration-ngspice.manifest.json` and `examples/resistor-calibration.spice` run actual ngspice45.2 in the pinned image. They verify local/companion transport, signed scalar values and artifact receipts. They make no Cadence/Synopsys/Siemens or foundry signoff claim.
