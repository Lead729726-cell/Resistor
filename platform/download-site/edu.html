앱 상단의 학습 프로젝트에서 현재 입력·기록 revision·실제 실행 상태를 비교하고 해당 실습을 이어 엽니다. QA 사본은 기본으로 숨깁니다. 연결 실패 시 다시 연결은 조회만 재시도하며 해석·제출·AI 요청을 중복 실행하지 않습니다.

배선: 핀 → 중간점 → 끝 핀

회로도에서 시작 핀을 클릭하고 다른 핀을 클릭하면 저장됩니다. 시작·도착 이름과 경로를 확인하세요. 노드 이름 충돌은 빨간 경고로 표시하며 엔진이 전체 경로를 최종 검사합니다. Space 꺾임 · Backspace 이전 점 · Esc/우클릭/취소 버튼. 명시적 모드에서는 빈 공간에서 연결을 추정하지 않습니다.

기기 초안과 서버 저장본이 다르면 두 내용을 확인한 뒤 직접 선택합니다. 미연결 상태에서는 이전 결과의 현재성을 확정하지 않습니다.

  • 기본 수치·선택 문제의 채점, 힌트와 해설은 추가 AI 호출 0회.

  • 해설 도움·반복 풀이·QA·AI 서술 평가는 자동 추천 근거에서 제외.
  • 새 AI 출제·피드백은 기존 비용 상한과 개별 전송 승인을 유지. AI 점수는 연습용.

DESIGN PRACTICE / 01

1. 실습 시작

기존 설계를 보존하고 새 프로젝트에서 시작합니다.

  1. 설계·시뮬레이션 학습 → CMOS 연결 실습을 엽니다.
  2. 새 인버터 실습을 만들거나 저장된 실습을 선택합니다. 기존 회로를 사용할 때도 별도 사본으로 시작합니다.
  3. project ID·revision·엔진·공정 식별 정보를 확인합니다.

DESIGN PRACTICE / 02

2. 연결 관찰

회로의 핀·net과 물리 도형의 대응 근거를 읽습니다.

  1. MN1 / MP1을 선택하고 입력 A, 출력 Y, 전원과 body 연결을 확인합니다.
  2. 회로도·레이아웃 열기로 대응 화면을 관찰하고 실습을 다시 엽니다. 마지막 페이지가 유지됩니다.
  3. net 주석은 관찰 후보입니다. device_id 근거가 없으면 연결 불명으로 두며 LVS 성공으로 표시하지 않습니다.
블록을 원하는 위치에 배치하기

캔버스에서 B로 셀·핀을 검색하고 선택합니다. 미리보기의 좌표를 보며 클릭으로 반복 배치하세요. R 회전 · Shift+R 반전 · Esc 취소 · Ctrl/Cmd+Z 실행 취소. 핀은 미연결 상태로 시작하며 배선 후 연결 검사를 실행합니다.

DESIGN PRACTICE / 03

3. 적층 확인

층의 표시 높이와 실제 공정 정보를 구분합니다.

  1. 표시 적층 3D 또는 절단을 열고 layer mapping과 Z축 추가 배율을 읽습니다.
  2. 표시용 높이·두께와 실제 공정 입력을 별도로 확인합니다. 미입력 값은 추정하지 않습니다.
  3. 레이어 돌출·절단은 시각화입니다. GDS만으로 재료·피복·공정 단면을 확정하지 않습니다.

DESIGN PRACTICE / 04

4. 기준 해석

한 변수를 바꾸기 전에 실제 기준 결과를 만듭니다.

  1. 앱의 변경 전 실제 해석 버튼으로 5 fF 기준 조건을 실행합니다.
  2. TT·27°C·1.8 V와 실제 ngspice run ID·revision·실행 상태를 확인합니다.
  3. 엔진·모델이 없거나 실행이 실패하면 이유를 확인합니다. 샘플 파형이나 단계 이동으로 PASS를 만들지 않습니다.

DESIGN PRACTICE / 05

5. 조건 변경

출력 부하 하나만 바꿔 설계 revision의 차이를 만듭니다.

  1. 기준 해석 완료 후 출력 부하를 1~1000 fF 범위에서 입력합니다.
  2. 부하 변경 적용을 누릅니다. 같은 입력·MOS 모델·마스크에서 ideal CLOAD만 바뀝니다.
  3. 이전·다음 이동 중 입력을 유지합니다. 이전 해석은 원래 revision의 결과로 남습니다.

DESIGN PRACTICE / 06

6. 재해석·비교

두 실제 실행의 차이를 같은 조건에서 해석합니다.

  1. 변경 후 실제 해석을 실행하고 기준/변경 run의 부하·revision을 비교합니다.
  2. 상승·하강 시간과 입력→출력 50% 지연을 읽습니다. 수치가 모두 없으면 비교할 수 없다고 표시합니다.
  3. DRC·LVS·PEX는 독립된 실행입니다. 시뮬레이션의 성공이 다른 검사나 제조 승인을 뜻하지 않습니다.

DESIGN PRACTICE / 07

7. 설명·저장

관찰한 사실과 근거를 자신의 말로 기록합니다.

  1. 관찰한 사실 → 적용한 모델/규칙 → 판단 근거 → 다음 실험 순서로 설명합니다.
  2. 사전·사후 개념 답과 설명을 학생 설명·조건·결과 저장으로 확정합니다. 기기 임시 초안과 구분합니다.
  3. 저장된 실습을 다시 열어 설명·조건·결과를 확인합니다. 페이지 위치는 학습 화면 상태이며 검증 완료 판정이 아닙니다.
