설치하고, 엔진을 연결하세요.

  1. Windows는 EXE를 실행합니다. Mac은 ZIP 전체를 풀고 Install Resistor.command로 설치합니다. Linux는 tar.gz 전체를 풀고 ./install.sh를 실행합니다.
  2. 회로·물리 해석에는 Docker Linux 엔진이 필요합니다. Windows·Mac에서는 Docker Desktop을 사용합니다. 앱의 설계 엔진 다시 연결로 상태를 확인합니다.
  3. 뷰어로 사용할 때는 파일을 열어 도형을 확인합니다. 전류·전압 표시는 실제 해석 결과가 필요합니다.

Mac 설치 도우미가 차단되면 출처와 SHA-256을 확인한 뒤 터미널의 /bin/zsh 뒤에 도우미 파일을 끌어 넣어 실행하세요. 설치·복구 안내에서 검증 범위를 확인할 수 있습니다.
