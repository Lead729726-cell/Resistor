먼저 실행 환경을 준비하세요

새 template adapter가 필요합니다. 공개 0.28 설치 파일에는 이 네 프로젝트가 아직 포함되지 않았습니다. 최신 공통 소스에서 npm ci 후 npm run dev:indust로 실행하세요. 기존 설계는 보존하고 새 프로젝트를 만듭니다.

  1. 프로젝트 도구 → 내 반도체 → 발진기·센서 프로젝트를 선택합니다. 또는 워크스페이스에서 프로젝트 ZIP을 가져옵니다.
  2. 기본 TRAN 설정을 유지하고 실제 해석을 실행합니다. 실행 전에는 결과가 없습니다.
  3. 시뮬레이션에서 노드·전류 파형과 명시된 파형 기준을 읽습니다. 회로를 바꾸면 이전 결과는 과거 revision의 기록입니다.

검증 범위: 네 회로의 TT/SS/FF, 프로젝트 재가져오기·재실행, 센서 C 변화와 링 부하 변화. 원본 파형·실행 manifest·source hash는 공개 저장소에 보존합니다.

발진 · 5단 CMOS 링 클록

부하가 클록을 얼마나 늦추는지 살펴보기

10개 실제 SKY130 MOS · 5단 지연 링 · 외부 클록 없음 · 이상적 단계 부하

Q0 → Q1 → Q2 → Q3 → OUT → Q0
편집 가능한 프로젝트 ↓회로 SPICE실제 파형 원본측정·검사 JSON
  1. 단계 C=2pF로 TRAN을 실행하고 Q0·Q1·OUT의 순차 전환을 겹쳐 봅니다.
  2. C=4pF로 별도 프로젝트를 만들어 주파수와 공급 전류를 비교합니다.
  3. TT/27°C/1.8V와 SS/125°C/1.62V, FF/−40°C/1.8V를 각각 실행합니다.
공식과 실제 3개 운전 조건

f = 1 / T, 평균 단계 지연 ≈ T / (2 × 5). 단계별 동일 지연을 가정한 환산값입니다.

센서 · 정전용량 → 주파수

정전용량 변화를 주파수로 바꾸는 터치·근접 센서의 출발점

6개 실제 MOS + 저항 양의 피드백 · 이상적 센서 C · 외부 클록 없음

OUT → R_TIMING → CAP → 저항 피드백 인버터 → OUT
편집 가능한 프로젝트 ↓회로 SPICE실제 파형 원본측정·검사 JSON
  1. OUT과 CAP을 겹쳐 커패시터 충·방전 및 실제 전환 전압을 확인합니다.
  2. 동일 R에서 C=5pF·10pF·20pF로 세 프로젝트를 만들고 주파수를 비교합니다.
  3. 전환 전압으로 계산한 이상적 RC 기준과 MOS 해석의 차이를 설명합니다. 실제 손가락·전극 모델과 보정은 추가해야 합니다.
공식과 실제 3개 운전 조건

Tideal = RC { ln[(VHIGH−VL)/(VHIGH−VH)] + ln[(VH−VLOW)/(VL−VLOW)] }. 실제 전환 전압을 사용하되 피드백 부하·MOS 지연·기생 성분은 포함하지 않은 비교식입니다.

센서 · 두 링 발진기의 비트 검출

빠른 두 발진기의 차이를 더 느린 비트 파형으로 읽기

독립 5단 링 2개 + 실제 CMOS XOR + 이상적 RC · Δf 읽기

REFERENCE_RING + SENSOR_RING → CMOS XOR → RC → OUT
편집 가능한 프로젝트 ↓회로 SPICE실제 파형 원본측정·검사 JSON
  1. REF와 SENSE가 외부 클록 없이 독립적으로 발진하는지 확인합니다.
  2. XOR와 저역통과 OUT을 함께 읽고 주파수 차와 관측 비트 주파수를 대조합니다.
  3. SENSOR 링의 C 증가율을 5~30% 범위에서 바꾸어 봅니다. 차이가 너무 작거나 필터가 부적절하면 관측 시간·필터를 조정하고 실패 항목을 읽습니다.
공식과 실제 3개 운전 조건

fbeat ≈ |fREF − fSENSE|. OUT은 XOR 듀티를 RC로 평균한 파형입니다. 실제 출력의 반복 주기와 독립 링들의 주파수 차를 비교합니다.

저전력 · 이벤트 구동 버스트 클록

이벤트가 있을 때만 동작하는 웨이크업 클록

NAND + 인버터 4단 링 · 외부 EN 2개 구간 · 발진 출력은 실제 MOS 해석

외부 EN → NAND + 인버터 4단 링 → OUT
편집 가능한 프로젝트 ↓회로 SPICE실제 파형 원본측정·검사 JSON
  1. EN·OUT을 겹쳐 두 번의 시작·정지 구간을 확인합니다.
  2. EN=LOW에서 OUT이 HIGH로 정지하는지, 두 번째 EN에서도 다시 발진하는지 확인합니다.
  3. 실행 결과의 구간별 공급 전력을 비교합니다. 전력 절감 비율은 실제 조건의 측정으로 판단하고 누설·부하·EN 구동 전력 범위를 명시합니다.
공식과 실제 3개 운전 조건

Pavg = VDD × ∫ I(VDD) dt / Δt. EN 입력의 외부 드라이버 전력은 포함하지 않습니다.

설계에 참고한 공식 자료

히스테리시스와 RC 발진 원리를 참고했으며 TI 제품 회로나 사양을 복제하지 않았습니다. 실제 회로는 별도의 SKY130 MOS 그래프입니다.

  • TI · Understanding Schmitt Triggers, SCEA046B (2025)
  • TI · Relaxation Oscillator Circuit, SNOA998A (2024)

비어 있는 교환용 OASIS는 칩 레이아웃이 아닙니다. 초기 조건과 이상적 R/C를 사용했으며 DRC/LVS/PEX·확률적 지터·위상 잡음·제조 승인은 별도입니다.
