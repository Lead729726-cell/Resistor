ENGINEERING WORKBENCH

Resistor Industry

현재 프로젝트·revision·다음 실행·실제 결과를 중심으로 전문 작업을 이어갑니다.

  • 회로·계층·정수 DBU 레이아웃·파일 입출력

  • 기존 설계 폴더와 API 보존
Industry 버전 다운로드 →npm run dev:indust

실행과 검증 범위

Node.js 24에서 의존성을 설치하고 npm run native:prepare로 공개 엔진을 준비하세요. 빌드 명령은 npm run build:edu / npm run build:indust입니다.

이번 분리는 소스 버전입니다. 배포 중인 v0.27.0 설치 파일을 Edu 전용 설치 파일로 표시하지 않습니다. Industry는 전문 작업 흐름을 뜻하며 제조 인증을 뜻하지 않습니다.
