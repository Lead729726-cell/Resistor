실행 취소와 지원 범위

입력 칸에서는 글자 입력과 기본 텍스트 Undo를 유지합니다. F1과 프로젝트 저장 외의 설계 단축키는 입력 중에 실행하지 않습니다. 설정창·안내창이 열려 있으면 배경 설계 키를 차단하며, IME 조합·키를 길게 누르는 반복 입력·읽기 전용·저장 진행 상태도 보호합니다.

Virtuoso의 앱·버전별 bindkey는 다를 수 있습니다. 이 설정은 지원 작업을 기준으로 하며, 요청에 따라 Ctrl/⌘+Z를 줌 대신 실행 취소로 사용합니다. 회로도 M은 순수 이동이고 배선 Stretch·DRD·자동 Via는 미지원입니다.

Delete는 선택한 항목을 삭제합니다. Mac의 ⌫도 지원하며, 초안의 이전 점 취소는 Ctrl/⌘+Z 또는 U, 다시 실행은 Ctrl/⌘+Shift+Z 또는 Shift+U입니다. 초안이 없으면 실제 엔진 이력을 취소합니다. Backspace는 점 취소에 사용하지 않습니다. Layout 2D 방향키는 1 grid, Shift+방향키는 10 grid입니다. 회로도에서는 각각 10/100 unit입니다. 이동 후 연결·DRC 상태는 별도로 검사하세요.

레이아웃 R은 사각형, 회로도 R은 회전입니다. Shift+P는 레이아웃 다각형, P는 레이아웃 Path 또는 회로도 Port입니다. 회로도 Shift+R은 반전, Alt+R은 저항 배치입니다. Ctrl/⌘+D는 선택 해제, Ctrl/⌘+Shift+D는 즉시 복제입니다. 미실행 검증을 성공으로 표시하지 않습니다.
