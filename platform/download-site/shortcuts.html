일치하는 단축키가 없습니다.

입력과 설계 데이터를 구분합니다.

입력 칸에서는 글자 입력과 기본 텍스트 Undo를 유지합니다. F1과 프로젝트 저장 외의 설계 단축키는 입력 중에 실행하지 않습니다. 설정창·안내창이 열려 있으면 배경 설계 키를 차단하며, IME 조합·키를 길게 누르는 반복 입력·읽기 전용·저장 진행 상태도 보호합니다.

Delete는 선택한 항목을 삭제합니다. Mac의 ⌫도 지원하며, 그리기 도구에서 Backspace는 이전 클릭을 취소합니다. Layout 2D 방향키는 1 grid, Shift+방향키는 10 grid입니다. 회로도에서는 각각 10/100 unit입니다. 이동 후 연결·DRC 상태는 별도로 검사하세요.

레이아웃 R은 사각형, 회로도 R은 회전입니다. 회로도 Shift+R은 저항 배치입니다. Ctrl/⌘+D의 레이아웃 복사는 마스크만 복제하고, 회로도 복사는 소자·배선을 복제합니다. 미실행 검증을 성공으로 표시하지 않습니다.
