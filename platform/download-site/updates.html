앱에서 바로 업데이트

v0.23부터 지원합니다. 현재 v0.27.0에서도 인터넷 연결 시 새 버전을 확인하고, 다운로드·파일 검증·설치를 앱에서 진행할 수 있습니다. 기존 설계 저장 폴더와 실행 중인 Docker 해석은 유지합니다.

v0.22 이하에서는 이번 버전을 한 번 직접 설치하세요. 이전 앱에는 업데이트 버튼이 없습니다.

운영체제별 새 설치 파일 받기 →전체 사용법·검증 범위 →

업데이트 순서

  1. 앱의 업데이트 → 지금 확인을 누릅니다. 자동 확인은 시작·인터넷 재연결 시와 6시간 간격으로 실행하며 끌 수 있습니다.
  2. 변경 내용과 운영체제를 확인하고 업데이트 다운로드를 누릅니다. 진행률은 실제 받은 바이트로 표시합니다. 취소·재시도가 가능합니다.
  3. 공식 GitHub 자산의 크기와 SHA-256이 일치해야 설치 버튼이 활성화됩니다.
  4. 입력 중인 설정과 뷰어 파일을 저장한 뒤 설치하고 다시 시작을 누르고 설치 확인창에서 진행합니다.

운영체제별 적용

운영체제설치 방식
Windows x64검증된 설치 안내를 엽니다. 기존 설치 폴더를 선택하고 완료 후 실행을 선택하세요.
Mac M1 이후 / Intel번들·아키텍처·자체 서명을 검사하고 사용자 Applications에 교체합니다. 기존 앱은 백업합니다.
Linux x64사용자 버전 폴더에 설치하고 애플리케이션 메뉴를 갱신합니다.
브라우저 / 소스 실행공식 버전 확인과 다운로드를 제공합니다. 소스 실행 중 앱 교체는 차단합니다.

실패와 복구

오프라인·서버 오류·파일 변조를 성공으로 표시하지 않습니다. Mac·Linux 교체나 실행 요청이 실패하면 이전 대상 앱을 복구하고 실패한 새 파일도 보관합니다. 설치 영수증·캐시는 사용자 데이터의 updates 폴더에 기록합니다. Windows 설치 취소는 기존 앱을 다시 열어 복구할 수 있습니다.

앱과 해석 엔진

앱 업데이트가 실행 중인 Docker 엔진을 강제 교체하지 않습니다. 해석 엔진 업데이트와 제조 검증 결과는 별도입니다. 키·프로젝트·PDK를 업데이트 서버에 보내지 않습니다.

현재 배포는 미리보기입니다. Apple 공증과 Windows Authenticode 서명은 아직 없습니다. 파일 해시 검증은 OS 배포 인증을 대신하지 않습니다. 모든 플랫폼의 GUI 설치·재실행까지 검증됐다는 의미는 아니며, 실제 검증 기록을 확인하세요.
