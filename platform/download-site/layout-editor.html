정확한 입력과 실제 검사

좌표는 공정 격자에 정확하게 맞아야 하며 잘못된 값을 자동으로 반올림하지 않습니다. 배선 폭은 양쪽 가장자리가 격자에 맞는 2×grid의 양의 배수여야 합니다. 잠긴 레이어, 공유 하위 셀·PCell은 직접 수정하지 않습니다.

복사는 마스크 도형을 복제하고 새 ID를 만듭니다. 회로의 소자·노드·연결을 함께 복사하려면 계층 가져오기를 사용하세요. 미저장 미리보기와 실제 도형을 구분하며 DRC는 따로 실행합니다. LVS·PEX·시뮬레이션은 파일·PDK → PDK·해석 설정에서 실제 reference SPICE와 모델·해석 조건을 연결하세요.

이 화면의 예제는 편집 조작용이며 DRC/LVS/PEX 미실행입니다. 별도 native 편집 시험에서는 실제 Magic DRC를 실행했습니다. Mac 직접 실행·Apple 공증과 파운드리 signoff는 이 시험으로 입증되지 않습니다.
