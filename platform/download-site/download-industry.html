설치 방법과 서명 상태

Windows는 EXE를 실행합니다. Mac은 ZIP 전체를 풀고 설치 도우미를 사용하세요. Linux는 tar.gz를 풀고 install.sh를 실행합니다. 기본 편집·ngspice는 Docker 없이 실행됩니다.

Windows Authenticode·Mac Developer ID / Apple 공증은 미완료입니다. Mac 경고가 발생하면 출처와 SHA-256을 확인한 뒤 설치 안내를 확인하세요. 시스템 전체 보안 설정을 변경할 필요는 없습니다.

소스 실행

Node.js 24 설치 후 폴더에서 실행하세요.

npm ci
npm run native:prepare
npm run dev:indust

소스의 최신 revision은 설치 파일의 빌드 revision과 다를 수 있습니다. 각 설치 파일의 검증 기록에서 정확한 소스를 확인하세요.
