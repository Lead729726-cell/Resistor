논문을 검토하고, 실제 회로를 다시 측정합니다

2026-10-13 검토 · 54개 회로 템플릿과 가산기·CPU 5종. 접근 가능한 2025–2026 자료를 중심으로 개선했으며 2024 배치 자료는 기초 자료로 구분합니다. 논문 칩의 성능 재현과 현재 SKY130 회로의 결과를 구분합니다.

편집 프로젝트·GDS/OASIS·해석 기록 ZIP전체 문헌 JSON실제 검증 기록 JSON전체 변경·재현 방법
현재 기록: 기본 59종 실제 해석 완료 · DRC 13 / LVS 13 / PEX 13회. 선택한 보상 저항 조건의 기능 FAIL 3개와 PSRR 측정-only UNKNOWN을 보존합니다. 소스 9eb7adb9a008. TT/지정된 SS·FF 및 typical RC 범위이며 제조 승인은 아닙니다.

바뀐 사용 흐름

  1. 앱에서 설계 도구 → 통합 설계 → 논문 · 특성 측정을 엽니다. 셀·블록을 검색하고 원문·적용·미재현 범위를 확인합니다.
  2. 회로 설정에서 기본 셀 ×1/×2/×4와 입력 slew, OTA의 보상 저항을 선택합니다. 기본 회로·기존 프로젝트는 보존합니다.
  3. 실제로 해석·DRC/LVS/PEX를 실행합니다. 단일 입력 타이밍 arc, 공급 전력, LDO PSRR, SAR acquisition/reset·conversion 에너지 또는 CIC 이론 응답을 읽습니다.
  4. stale은 이전 소스·설계의 기록입니다. 새 문헌 목록 자체가 PASS를 만들지 않습니다. 실행 중인 이전 Docker 엔진은 해석을 끝낸 뒤 중지하고 새 앱에서 다시 연결하세요.

코드 폭 8bit는 8 ENOB가 아닙니다. VDD/VREF만 측정한 에너지는 입력·바이어스·클록·컨트롤러까지 포함한 총전력이 아닙니다. 소신호 PSRR의 AC=1은 전달함수 정규화이며 1V의 실제 대신호 리플 검증이 아닙니다.
