0.9V 중심 ±0.6V, 183.10546875Hz 조건입니다. 8비트 출력은 유효 해상도 8비트 인증을 뜻하지 않습니다. 열잡음·flicker·jitter·Monte Carlo·전체 PVT·제조 마스크·DRC/LVS/PEX는 미검증입니다.

앱에서 시작하기

  1. Resistor v0.24.0를 설치하고 Docker Linux 설계 엔진을 연결합니다.
  2. 설계 도구 → 통합 설계 → 회로 · 연결 탐색 → 회로 template 지원 범위 읽기를 누릅니다.
  3. 19개 실제 회로 프로젝트 생성을 누르면 각 블록과 전체 ADC를 만듭니다. 기존 블록은 기존 ADC 블록 프로젝트 읽기 → 블록 열기로 엽니다.
  4. Schematic의 Hierarchy에서 MODULATOR·DECIMATOR와 내부 소자를 엽니다. R/C/MOS 값과 연결을 편집하고 회로 검사·SPICE 내보내기를 사용합니다.
  5. Simulate로 실제 해석을 실행합니다. 기본 입력 0.9V에서 평균 CODE 128, DC 오차 0 LSB를 확인했습니다. CODE·VALID·입력·비트열·적분기·공급 전류와 결과 파일 위치를 확인합니다.
  6. 사인파 검사는 새 전체 ADC의 입력 0.9V, 진폭 0.6V, 주파수 183.10546875Hz를 설정하고 Testbench duration 16.908ms, step 125ns로 실행합니다. 첫 두 프레임을 제외한 64개 출력으로 SINAD/ENOB를 계산합니다.

아날로그 단독 블록은 연결된 모듈레이터 검사 환경에서, 디지털 단독 블록은 필터 검사 환경에서 실행합니다. 아날로그 전류는 공급 전류 합계이며 내부 소자 전류·디지털 RTL 전력은 포함하지 않습니다. 디지털 회로 변경 후에는 RTL와 합성 회로를 맞춰야 하며 이전 RTL를 조용히 재사용하지 않습니다.
