TT · 27°C · 1.8V · typical RC의 이름 있는 검증 기준입니다. 넓은 1행 참조 배선이며 matching·ESD·패드·제조 승인은 별도입니다. ADC·CPU가 모두 결합된 완성 SoC는 아닙니다.

직접 열고 실행하기

  1. Resistor v0.20.0와 Docker 설계 엔진을 준비합니다.
  2. 설계 도구 → 통합 설계 → 회로 · 연결 탐색 → 회로 template 지원 범위 읽기를 누릅니다.
  3. 7개 SoC 회로 생성 · 센서 AFE 열기로 계층 프로젝트를 만듭니다. 기존 프로젝트는 기존 SoC 블록 프로젝트 읽기 → SoC 블록 열기에서 엽니다.
  4. Hierarchy에서 OTA 입력단·보상·게이트와 피드백 저항을 엽니다. 하위 계층을 복사할 때 미리보기로 연결과 배치 영향을 확인하세요.
  5. Simulate로 실제 소자 해석을 실행합니다. 기본 입력은 0.9V 중심 ±25mV·5kHz, GAIN은 100µs에 바뀝니다. CLK=1MHz, RESET은 첫 5µs입니다. 전류·전압강하·OUT·DATA와 파형 검사 결과를 확인합니다.
  6. 물리 프로젝트는 ZIP을 가져오거나, 아래 회로 선택에서 실제 physical core 요청을 켜 별도로 생성합니다. DRC/LVS/PEX와 pre/post 해석을 각각 실행합니다. 생성은 검증 PASS가 아닙니다.

전후 해석과 정확한 공식

PGA: A=1+Rf/Rg. 저이득 경로는 실제 MOS 스위치의 R_on을 포함하므로 정확히 2.000배가 아닙니다. 필터의 이상적 H(s)=1/(1+sRC)²이고, 실제 레이아웃 후 −3dB 대역폭은 121.80kHz입니다. TIA는 Iin→Vout 변환이며 기준 방향은 입력 노드에서 접지로 흐르는 전류입니다.
