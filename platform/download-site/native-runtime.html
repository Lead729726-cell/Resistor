v0.27.0 · Docker-free native engine

Docker 없이 회로를 그리고, 실제 응답을 확인하세요.

기본 설치 파일에 Python·KLayout·ngspice·공개 SKY130A 자료가 들어 있습니다. 회로·레이아웃·GDS/OASIS·전압·전류 해석을 컴퓨터의 로컬 엔진에서 실행합니다. 설치 후 기본 엔진 시작에는 인터넷이나 로그인이 필요하지 않습니다.

운영체제별 시작

  1. Windows는 EXE, M1 이후 Mac은 arm64 ZIP, Intel Mac은 x64 ZIP을 받습니다. Linux는 x64 tar.gz를 받습니다.
  2. Mac은 ZIP 전체를 풀고 Install Resistor.command, Linux는 ./install.sh를 실행합니다. Mac은 macOS 13 이상이 필요합니다.
  3. 앱에서 설계 엔진 다시 연결을 누릅니다. 환경 진단의 기본 실행 방식은 로컬 · Docker 없이입니다.

설계 시작과 결과 확인이 쉬워졌습니다.

  • 새 프로젝트의 기본값은 빈 회로도입니다. 소자를 배치하기 전에는 필요한 입력을 안내합니다.
  • 열기에서 이름·공정·ID를 검색하고 50개씩 프로젝트를 확인합니다. 설계 파일 가져오기도 같은 화면에 있습니다.
  • 툴바의 다음 실행을 누르면 현재 설계의 준비 상태와 필요한 도구를 확인합니다. 실행 요청 가능은 PASS가 아닙니다.
  • 실행 목록·파형 선택·로그가 같은 결과를 참조합니다. 이전 결과의 원인과 현재 설계 번호를 함께 표시합니다.
  • 대화창에서는 Tab·Shift+Tab으로 이동하고 Escape로 닫습니다.

전체 물리 도구 준비

Mac/Linux 호스트, 또는 Docker와 독립된 Ubuntu WSL 터미널에서 제공 스크립트를 실행합니다. Windows 앱의 실행 방식에서 설치된 Ubuntu를 선택하세요. docker-desktop 내부 배포판은 연결하지 않습니다.

sh scripts/native-tools-setup.sh

Mac은 Homebrew·Xcode 개발 도구가 필요합니다. Linux/WSL은 패키지 설치 시 관리자 확인을 요청합니다. 앱 리소스 폴더의 동일 스크립트를 사용할 수 있습니다. 전체 절차·도구 버전·운영자 설정.

기존 작업에서 전환

해석·PVT·실험을 완료하거나 취소한 뒤 환경 진단의 기존 Docker 엔진에서 전환을 누릅니다. 현재 폴더·인증·소유권이 일치하는 유휴 엔진만 종료하며 컨테이너·볼륨·설계 데이터를 삭제하지 않습니다. 엔진이 바뀌면 이전 결과는 stale로 표시하고 원본 보고서는 보존합니다.

설치 경고와 검증 범위

Mac 자체 서명과 Apple Developer ID·공증은 서로 다른 상태입니다. Apple 공증은 완료하지 않았습니다. 도우미가 차단되면 파일 출처·SHA-256을 확인한 뒤 터미널의 /bin/zsh 뒤에 도우미 파일을 끌어 넣어 실행합니다. 설치·복구 안내.

기본 Windows 패키지에는 Magic/Netgen이 포함되지 않습니다. 공개 DRC/LVS/PEX 결과는 제조 승인·TCAD 검증과 구분합니다. 이전 녹화 튜토리얼의 Docker 절차는 해당 녹화 버전의 내용이며 v0.26의 기본 실행 절차는 이 가이드입니다.

소스에서 실행

npm ci
npm run native:prepare
npm run doctor
npm run dev:web

Node.js 24가 필요합니다. 최초 공개 도구 준비에는 인터넷, Mac/Linux ngspice 빌드에는 컴파일러가 필요합니다.
