압축을 푼 뒤 실행

Node.js 24 설치 후 압축을 푼 폴더에서 터미널을 열고 순서대로 실행하세요.

npm ci
npm run native:prepare
npm run dev:edu

최초 실행에는 공개 의존성·엔진 다운로드를 위한 인터넷이 필요합니다. 기본 편집·ngspice는 Docker 없이 사용하며, DRC/LVS/PEX의 추가 도구와 deck은 별도로 준비합니다.
