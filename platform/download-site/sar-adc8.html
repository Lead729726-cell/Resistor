8비트 SAR ADC와 칩 영역 규격

256개 동일 단위 커패시터와 실제 MOS 비교기의 8회 판단. 제어 순서는 RTL·합성 gate·CMOS 연결 회로를 실제 실행해 대조합니다.

SAR 계층·마스크·원본 결과 ZIP 7개 bounded SoC 회로 ZIP

소스 v0.22 이상에서 사용하세요. 8비트 출력과 8 ENOB는 별도이며 ENOB는 미측정입니다.

칩 제한: 1,000 × 1,000 µm · 1 mm²

기본 여백 10µm. 가로·세로·최대 면적을 직접 정하고 배선과 하위 계층까지 실제 경계로 검사합니다. 영역을 넘는 사각형·배선·인스턴스·가져오기는 저장되지 않습니다. 기존 프로젝트의 좌표는 보존하고 새로운 physical template에서 여러 줄로 다시 배치합니다.

SAR 아날로그 코어의 실제 경계: 873.720 × 289.810 µm · 0.253213 mm².

앱에서 만드는 순서

  1. 설계 도구 → 통합 설계 → 회로 · 연결 탐색 → 회로 catalog 읽기.
  2. SAR ADC 라이브러리에서 8개 블록 생성. ANALOG·CONTROL을 열어 하위 회로를 확인하세요.
  3. Simulate 실행 후 TOP, COMP, SAMPLE, CODE와 공급·기준 전류를 확인하세요.
  4. 샘플링 + CDAC + 비교기 코어 template와 physical core를 선택하고 칩 영역을 설정하세요.
  5. DRC/LVS/PEX를 각각 실행한 후 post-layout 해석을 별도로 실행하세요.
  6. 전체 코드 검사에는 새 프로젝트의 sweep_codes를 1로 설정합니다.

VTOP = VCM − VIN + VREF × trial / 256
기본 VREF 1.2V → 1 LSB 4.6875mV. 획득 2µs + 8 × 2µs = 변환 18µs. 실제 비교기 HIGH일 때 trial 비트를 유지합니다.

지원 범위와 남은 검증

아날로그 코어의 실제 물리 배치와 PEX를 지원합니다. 전체 SAR 제어기 마스크·트랜지스터 타이밍, 기준 버퍼, pad/ESD·기판 격리·전역 density/antenna·EM/IR·제조 승인은 별도입니다. 칩 영역 제한은 패드와 패키지를 포함한 제조 die 정의가 아닙니다. 미실행 검증은 PASS로 표시하지 않습니다.
