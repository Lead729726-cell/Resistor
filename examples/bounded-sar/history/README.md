# Preserved iterations

Each source folder retains its executed summary, source hashes, run IDs and the distinct SAR prototype failures. Repeated unchanged SoC mask folders are preserved in the originating workspace under .runtime/sar8/redundant-history-backup and immutable worker snapshots; current identical masks are in the main reference folders. No native run or original design was deleted.

The 100 fF prototype had 2-code post-layout error. The 400 fF version met code accuracy but left one comparator decision ambiguous. Real CMOS restoration and an explicitly modeled finite external control driver were added; tolerances and pass criteria were not relaxed.
