# Resistor Indust · 발진기와 센서 프로젝트

네 가지 편집 가능한 SKY130 회로를 공통 엔진에 추가했습니다. 발진 출력을 이상적인 PULSE나 계산식으로 대신하지 않습니다. 실제 MOS 과도 해석의 노드 전압과 공급 전류를 측정합니다. 기존 전류 제한 3단 VCO·PLL과 다른 비교 과제입니다.

| 프로젝트 | 구조와 용도 | 살펴볼 노드 |
|---|---|---|
| `osc_ring5` | 10 MOS, 5단 CMOS 링. 지연·부하·PVT 실험 | Q0–Q3, OUT |
| `osc_rc_sensor` | 6 MOS와 저항 양의 피드백. 정전용량을 주파수로 변환 | OUT, CAP, HYST, SUM |
| `osc_beat` | 독립 링 두 개, 실제 CMOS XOR, RC 저역통과. 센서의 작은 변화 읽기 | REF, SENSE, XOR, OUT |
| `osc_burst` | NAND와 인버터 4단. EN 구간에만 발진하는 이벤트 클록 | EN, Q0–Q3, OUT |

## 실행과 편집

새 adapter는 최신 소스 엔진에서 지원합니다. 공개된 0.28 설치 파일은 이번 변경을 포함하지 않습니다. [네이티브 실행 안내](native-runtime.md)에 따라 최신 소스를 실행합니다. Indust의 기존 설계 폴더와 Edu의 별도 폴더를 보존하세요.

1. **프로젝트 도구 → 내 반도체 → 설계 종류: 발진기·센서 프로젝트**를 선택합니다.
2. 회로와 운전 조건을 고릅니다. 필요하면 **생성 후 실제 해석도 실행하기**를 체크합니다.
3. **설계 도구 → 통합 설계 → 회로·연결 탐색 → 회로 template 지원 범위 읽기**에서도 네 회로를 선택할 수 있습니다. 아래 R/C 입력을 바꾸고 별도 프로젝트로 생성합니다.
4. **Simulation → TRAN**을 실행합니다. 프로젝트의 기본 관측 시간과 최대 간격은 회로의 R/C에 맞춰 설정됩니다. 임의의 느린 조건에서 충분한 주기를 관측하지 못하면 파형 기준은 실패합니다.
5. 결과에서 주파수·듀티·공급 전력·노드 전압과 전류를 읽습니다. 하위 셀은 회로도에서 내려가 편집할 수 있습니다. 편집 후에는 이전 결과가 과거 revision으로 표시됩니다.

[프로젝트와 원본 표본](../examples/oscillator-lab/README.md) · [전체 네이티브 검사 기록](evidence/oscillator-lab/native-verification.json).

## 권장 비교 과제

- **클록 부하:** 5단 링의 각 C를 2pF에서 4pF로 바꾸어 주파수와 공급 전력을 비교합니다. 평균 단계 지연 `T/10`은 동일 단계 지연을 가정한 환산값입니다.
- **터치·근접 센서의 회로 원형:** 동일 100kΩ에서 센서 C를 5pF·10pF·20pF로 바꿉니다. 실제 전극·손가락·환경 잡음·기생 성분·보정은 아직 모델링하지 않았습니다.
- **비트 검출:** REF와 SENSE의 주파수 차 `|fREF−fSENSE|`를 RC로 평균한 XOR 출력의 주기와 대조합니다. 반송파 리플의 이중 계수를 피하도록 실제 OUT 범위의 25% 히스테리시스 폭으로 교차점을 판별합니다. 파형을 합성하거나 보정한 출력으로 치환하지 않습니다.
- **이벤트 클록:** 두 EN 구간에서 시작·정지·재시작을 검사합니다. 공급 전력은 각 구간에서 시간 가중 적분합니다. 외부 EN 드라이버 전력은 포함하지 않습니다.

## 공식과 단위

전압은 V, 전류는 A, R은 Ω, C는 F, 시간은 s로 저장합니다.

실제 선형 보간 상승 교차점으로 완전한 주기를 측정합니다. 주기 세 개 이상, 충분한 표본 간격, 요청한 관측 구간의 끝까지 존재하는 데이터가 필요합니다. 듀티와 전력은 적응형 표본 밀도가 결과를 바꾸지 않도록 시간으로 적분합니다.

```
f = complete_cycles / (last_crossing − first_crossing)
Pavg = VDD × integral(Isupply dt) / observation_duration
Tideal_RC = R C [ln((VHIGH−VL)/(VHIGH−VH)) + ln((VH−VLOW)/(VL−VLOW))]
```

RC 식은 실제 전환 시점의 CAP 전압을 넣은 이상적 무부하 기준입니다. 저항 피드백의 부하, MOS 지연·누설과 기생 성분 때문에 실제 회로의 주기와 다릅니다. 회로의 상·하단 임계값을 임의로 VDD/3·2VDD/3로 고정하지 않습니다.

## 검증과 재생성

```sh
npm run test:oscillators
npm run examples:oscillators
npm run test:oscillator-ui
npm run build
```

네이티브 SDK와 공개 SKY130 모델이 필요합니다. 검사는 별도 임시 workspace·loopback 포트를 만들고 자기 소유 엔진만 종료합니다. 사용자 설계나 다른 edition의 엔진은 수정하지 않습니다.

실제 검사에는 네 회로의 TT/27°C/1.8V, SS/125°C/1.62V, FF/−40°C/1.8V, ZIP 재가져오기·재실행, 센서 C 두 조건, 링 부하 한 조건, 편집 후 결과의 stale 상태가 포함됩니다. 이상적 RC만으로 구성한 기존 필터의 PDK 없는 생성·해석도 회귀 검사합니다. 단위·공식·잘못된 입력·파형 손상 fixture는 실제 엔진 결과와 구분합니다.

## 참고 자료와 검증 범위

[TI Understanding Schmitt Triggers, SCEA046B (2025)](https://www.ti.com/lit/pdf/scea046)의 임계값·히스테리시스·느린 입력에서의 전류 설명과 [TI Relaxation Oscillator Circuit, SNOA998A (2024)](https://www.ti.com/lit/pdf/snoa998)의 RC 충·방전 원리를 참고했습니다. 이 회로는 별도로 작성한 SKY130 MOS 구조이며 TI 부품의 구현·정격·측정 성능을 재현하지 않습니다. 링·비트·버스트 구조 역시 TI 회로의 복제라는 의미가 아닙니다.

R/C는 이상적인 외부 소자입니다. 명시한 초기 전압은 결정론적 기동 조건이며 열잡음에 의한 실제 기동을 검증하지 않습니다. 결과의 주기 변동은 확률적 지터나 위상 잡음이 아닙니다. 칩 레이아웃은 생성하지 않았고 교환 ZIP의 빈 OASIS는 마스크가 아닙니다. DRC/LVS/PEX, 기생 후 성능, 소자 매칭·Monte Carlo·전체 PVT·센서 보정·제조 signoff는 이번 판정 범위에 포함하지 않습니다.
