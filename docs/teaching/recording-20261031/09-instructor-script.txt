Resistor Edu · 09 트랜지스터로 스위치 만들기
목표 10분 (시연 포함·계획) · 강사 직접 녹음 · 아직 녹화하지 않은 대본
NMOS의 단자·입력·부하 조건에 근거해 동작을 설명한다.

트랜지스터는 단자 연결과 모델 조건이 중요합니다. 여기서는 NMOS의 드레인을 OUT, 게이트를 IN, 소스와 벌크를 GND로 연결합니다. 출력에는 풀업 저항과 부하 커패시터가 있습니다.
이 시연은 공개 SKY130A의 nfet_01v8 TT 모델을 사용합니다. 같은 모델 이름이라도 입력 전압, 온도와 연결 조건이 달라지면 결과가 달라질 수 있습니다. 정확한 수치는 지금 실행한 파형과 커서에서 읽겠습니다.
대조 실험에서는 게이트 연결 하나만 GND로 바꾸겠습니다. OUT이 어떻게 달라지는지 먼저 예상해주세요. 부하 커패시터도 동시에 바꾸면 원인을 분리하기 어렵습니다. 전류를 계산하지 않은 상태에서 배치 그림만 보고 전류 값을 만들어내지는 않겠습니다.

화면 조작
1. D=OUT, G=IN, S=B=GND를 연결한다.
2. SKY130A nfet_01v8 TT·27°C·1.8 V와 실제 실행을 확인한다.
3. G만 GND로 바꾸고 대조 해석한다.
4. 부하 C 변경은 별도의 새 실험으로 진행한다.

학생 멈춤 질문: G=GND에서 OUT이 높게 남는 이유를 풀업 저항과 함께 설명해 보세요.
결과물: NMOS 기준/대조 실험 보고서 1편
다시 촬영: MOSFET을 이상 스위치라고 단정하거나 모든 공정에서 같은 숫자라고 말한 장면
