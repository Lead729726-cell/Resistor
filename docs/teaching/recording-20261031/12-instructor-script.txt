Resistor Edu · 12 나만의 실험 노트를 완성하기
목표 8분 (시연 포함·계획) · 강사 직접 녹음 · 아직 녹화하지 않은 대본
실험 결과와 판단의 근거를 재현 가능한 기록으로 제출한다.

마지막으로 세 가지 실험을 본인 보고서로 정리하겠습니다. 먼저 조건과 예상 방향, 그다음 실제로 관찰한 수치와 근거, 마지막으로 아직 모르는 것과 다음 실험을 씁니다. 모범 해설을 그대로 붙여 넣는 대신 자신의 입력과 결과를 설명해주세요.
워크북 계산으로 확인한 값인지 실제 ngspice 표본인지 구분하고, 실행하지 않은 DRC·LVS·PEX는 미실행으로 남깁니다. 학생이 완료를 체크했다고 정답 인증이나 제조 검증이 끝나는 것은 아닙니다.
JSON으로 내려받은 뒤 다시 열어 예측과 설명이 보존되는지 확인하겠습니다. 브라우저 저장 공간이 부족할 때는 실패 안내를 읽고 현재 기록을 별도로 보관합니다. 같은 결과를 다시 만들 수 있게 조건과 출처를 남겼다면 이번 과정의 목표를 완성한 것입니다.

화면 조작
1. 분압·RC·NMOS 각 실험의 조건·예측·결과·설명을 정리한다.
2. 계산/실제 해석/미확인을 나눠 적는다.
3. JSON을 내보내고 별도 빈 노트에서 검증 후 다시 연다.
4. 원문 보존과 revision·run을 확인하고 보고서를 인쇄한다.

학생 멈춤 질문: 다른 사람이 같은 결과를 재현하려면 내 보고서에 무엇이 있어야 할까요?
