이번 점검에서 확인한 중요한 수정

  • 5강 대본은 R2=20 kΩ로 통일합니다. 과거 R2=5 kΩ 버전과 혼용하지 않습니다.
  • 워크북 RC는 10 kΩ, 실제 동적 퍼즐의 기본 RC는 1 kΩ입니다. τ=10 µs와 1 µs를 화면 전환 때 구분합니다.
  • 기존 OBS 프로필 2개가 720p 출력입니다. 강의 전용 프로필의 출력 해상도를 직접 확인하세요.
  • 공식 시리얼 서버·가격의 인프런 관리자 저장·설치본 배포는 미확인입니다. 소스 실행 화면을 정식 배포 인증 성공으로 설명하지 않습니다.
  • 도구 설치와 검사 성공은 별개입니다. 오늘의 실제 엔진 검증 결과는 verification.json에서 확인합니다.
