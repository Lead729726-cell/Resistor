# 통합 EDA 설계 절차 · v0.8

상단 **통합 설계** 버튼에서 PVT 일괄 해석, PDK 배선 보조, 회로·연결 탐색을
사용합니다. 패널을 열기만 하면 엔진을 실행하지 않습니다. 설계·배선은 실제
worker의 정수 DBU 원본에 적용되고 해석은 실제 ngspice 결과를 사용합니다.

## 조건별 해석

프로젝트의 실제 공급원 목록을 읽고 전원 소자, 기존 testbench 전원 또는
가져온 GDS의 설정된 전압 포트를 선택합니다. 모델 profile이 선언한 코너와
온도·전압 목록, 실제 결과에서 읽을 metric과 제약을 입력합니다. 조건표 저장은
해석을 시작하지 않습니다. 저장된 입력을 확인한 뒤 실제 실행 버튼을 누릅니다.

최대 32개 조건을 원본 snapshot의 별도 프로젝트에서 해석합니다. 원본 설계는
변경하지 않습니다. 전체 시간, 조건별 시간, 동시 실행 한도를 적용하며 취소와
worker 재시작으로 중단된 결과를 성공으로 표시하지 않습니다. 조건별 실제 Run,
측정값, 로그, 원본 JSON과 CSV를 열 수 있습니다. 실패하거나 metric이 없는
조건에는 값을 채워 넣지 않습니다. 최소/최대 요약과 제약의 최악 조건은 실제
유효한 측정값으로 계산합니다. 원본 revision이나 사용한 모델이 바뀌면 STALE입니다.

일반 회로의 PVT는 선택한 전원 소자와 실제 IR netlist를 사용합니다. 설정된
자극의 범위와 지원 분석을 확인하세요. 이상적인 저항·커패시터만 있는 회로는
공정 코너를 바꿔도 결과가 같을 수 있습니다. 이 기능은 통계적 Monte Carlo
수율, foundry signoff, 상용 엔진의 실제 실행 검증을 제공하지 않습니다.

## 배선 미리보기와 적용

실제 설치 PDK 규칙을 읽은 뒤 지원 레이어, 시작/끝 DBU 좌표, 폭과 순서를
선택합니다. width·grid·area와 기존 도형의 충돌/spacing을 검사합니다. 미리보기는
원본을 바꾸지 않습니다. 적용 시 worker가 원본 revision, 규칙 리소스 해시,
입력/경로 해시를 다시 검사하고 한 번의 undo 가능한 revision으로 적용합니다.
다른 공동 설계자가 도형을 바꾸면 새로 미리 보아야 합니다.

현재 범위는 공개 SKY130 met1의 보수적인 단일 레이어 Manhattan 경로입니다.
via·접촉·antenna·다중 레이어 자동 배선과 전체 DRC를 대신하지 않습니다.
**적용 뒤 실제 DRC 버튼으로 전체 물리 규칙을 확인하세요.** net 속성은 경로의
설계 메타데이터이며 전기적 연결이나 LVS 통과 증거가 아닙니다.

규칙의 기준: [SKY130 공식 periphery 규칙](https://skywater-pdk.readthedocs.io/en/main/rules/periphery.html).
실제 적용 값과 profile/resource 해시는 worker 응답에 기록합니다.

## 회로 템플릿과 연결 탐색

카탈로그를 읽고 지원 회로와 숫자 파라미터를 선택해 새 로컬 프로젝트를
생성합니다. 실제 소자·핀·넷·포트 및 자극이 있는 편집 가능한 회로입니다.
회로도에서 편집하고 실제 OP/DC/AC/transient와 파형 기반 측정을 실행합니다.
미생성 레이아웃을 검증된 physical 설계로 표시하지 않습니다. 물리 core를
지원하는 경우도 최종 DRC/LVS/PEX 결과는 각각 실행해 확인해야 합니다.

현재 카탈로그는 RC 저역통과, 공통 소스, 저항 바이어스 공통 소스,
전류 미러, 차동쌍, 4:1 MUX 6개 회로입니다. 각 회로의 실제 공급원과 지원 분석은
worker가 반환합니다. 예를 들어 RC의 VIN 조건표는 transient 해석을 사용하며,
전류 미러에서 sweep하는 출력 전원을 PVT 공급원으로 중복 지정할 수 없습니다.

상단 **내 반도체**에서는 CMOS·MOS 예제를 포함한 8개 역할별 시작 설계와
기본·저전압 고온·빠른 코너 저온 운전 조건을 함께 선택할 수 있습니다.
[미리 만들어보는 내 반도체](semiconductor-starters.md).

공개 모델의 기본 파라미터로 실행한 검증에서 RC 시정수는 약 10.0005 ns,
차단 주파수는 약 15.9147 MHz였습니다. 이 값은 실제 파형에서 계산한 예이며
사용자가 회로나 조건을 바꾸면 새 Run의 측정값으로 확인해야 합니다.
입력/측정 정의와 결과는 `evidence/design-tools.json`에 기록합니다.

연결 탐색은 실제 회로도의 pin/net와 검사 오류를 표시합니다. 화면의 물리
도형은 명시적인 device ID가 있는 경우에만 연결합니다. 같은 net 이름만 보고
추출된 전기적 연결이나 대응 소자를 추측하지 않습니다. 레이아웃 매핑이
미확인인 경우 회로도 연결을 확인하고 실제 LVS를 실행하세요.

공동 설계자는 공유 프로젝트에서 조건표 읽기·해석과 배선 적용을 사용할 수
있습니다. Viewer는 조회만 가능합니다. 새 템플릿은 로컬에서 생성한 뒤 기존
공동 작업 패널의 프로젝트 공유 절차로 공유합니다. 인터넷 서버 배포는 보류합니다.
