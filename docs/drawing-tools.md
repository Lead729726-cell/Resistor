# 레이아웃·회로도 직접 그리기

## 레이아웃

**F1 / ? / Ctrl·⌘+/** 또는 상단 **단축키** 버튼으로 안내창을 엽니다.
화면별 분류와 검색을 지원합니다. [전체 단축키 표](shortcuts.md).

**새 프로젝트 → 빈 SKY130 레이아웃 · 직접 그리기**로 시작하면 실제 도형이 없는
SKY130A 프로젝트를 만듭니다. 19개 마스크 목적이 준비되어 있으며, 첫 도형을
저장하거나 모두 삭제한 뒤에도 레이어 목록을 유지합니다.

**Layout 2D** 상단에서 **사각형**, **다각형**, **배선 그리기**를 선택합니다.
**작업 레이어**와 Net을 지정하고 화면을 클릭하세요.

- 사각형 / R: 대각선으로 드래그하거나 두 모서리를 클릭하면 저장합니다.
- 다각형 / P: 꼭짓점을 클릭한 후 Enter 또는 시작점 클릭으로 완료합니다.
- 배선 / W: conductor 레이어와 폭(DBU 또는 µm)을 지정하고 경유점을 클릭합니다. Enter로 저장합니다.
  Space는 다음 구간의 X→Y / Y→X 꺾임 순서를 바꿉니다.
- 이동 / M: 도형을 드래그하거나 오른쪽 속성의 ΔX/ΔY를 입력합니다.
- 복사 / C: 원본 도형과 새 위치를 클릭합니다. 오른쪽 속성에서 복사 거리로도 생성할 수 있습니다.
- 사각형을 선택하면 오른쪽에서 X₁/Y₁/X₂/Y₂, 레이어, Net을 수정하고 **사각형 변경 적용**을 누릅니다.
  µm↔DBU 단위 전환은 입력 중인 값까지 정확하게 변환합니다.
- Delete 또는 **도형 삭제**, Ctrl/⌘+Z 실행 취소, Ctrl/⌘+Shift+Z 다시 실행.
- Backspace는 이전 클릭을 취소합니다. Esc는 미저장 도형을 취소하고 선택 모드로 돌아갑니다.
- F는 전체 맞춤입니다. 휠로 확대하고 우클릭 드래그로 화면을 이동할 수 있습니다.
  저장한 뒤 화면 범위를 유지하며, 기존 숫자 입력 도구도 유지됩니다.

R/P/W/M/C/F 단축키는 레이아웃 캔버스에 포커스가 있을 때 작동합니다.
도형 복사는 마스크만 복사합니다. 새 도형 ID를 만들며 원본은 보존하고,
소자 ID를 복제하지 않습니다. 회로의 소자·노드·배선을 함께 복제하려면 계층 가져오기를 사용하세요.
공유 하위 셀·PCell은 직접 편집하지 않으며, 실제 사각형 primitive만 좌표 편집을 지원합니다.

좌표는 프로젝트의 절대 정수 DBU 격자에 맞춰 저장합니다. 배선 양쪽 가장자리가
격자에 맞도록 폭은 `2 × grid_dbu`의 양의 배수여야 합니다. 예를 들어 5 DBU
격자에서는 200 DBU가 유효하고 205 DBU는 거부됩니다. 잠긴 레이어, 읽기 전용
설계, 면적 0, 다각형 자기 교차, 좌표 범위 오류는 저장을 차단합니다.
레이어 변경이나 새 설계 revision을 수신하면 진행 중인 레이아웃 초안은 취소됩니다.

청록/강조색 선과 배선 폭 외곽은 **미저장 가이드**입니다. 실제 도형은 KLayout
엔진이 저장한 뒤 새 revision에서 표시합니다. 그리기 미리보기는 DRC 결과가
아닙니다. DRC는 실제 도형을 만든 뒤 별도로 실행하세요. 빈 수동 레이아웃은 검사하지 않습니다.
LVS·PEX·시뮬레이션은 **파일·PDK → PDK·해석 설정**에서 실제 reference SPICE,
모델·추출·해석 조건을 연결한 뒤 실행합니다. 미실행을 PASS로 표시하지 않습니다.

## 회로도

**회로도 / Schematic**의 소자 배치 줄에서 저항·커패시터·전압원·전류원·NMOS·PMOS·
GND·Port를 선택합니다. 이동하는 기호는 미배치 미리보기이며 클릭하면 실제
소자를 저장합니다. 도구를 다시 선택하지 않고 반복 배치할 수 있습니다.
새 이름은 기존 이름과 대소문자가 겹치지 않도록 생성합니다. 값은 기존 동일 종류
소자의 값을 복사하거나 SI 기본값을 사용하며 소자 간 파라미터 객체를 공유하지 않습니다.

배치 중 **R**은 90° 회전, **M**은 좌우 반전, **Esc**는 배치 취소입니다.
선택 모드에서는 R/M 또는 같은 버튼으로 선택한 소자를 변환합니다. 모델, 회로
노드와 파라미터 값은 유지합니다. 기호를 반전한 후 회전하는 순서로 핀 위치를
계산하며 화면과 native 연결 검사가 같은 좌표를 사용합니다.

**배선 / Wire**에서 핀을 클릭해 시작하고 경유점 또는 끝 핀을 클릭하세요.
Space는 다음 꺾임 방향, Backspace는 이전 점 취소, Enter는 완료, Esc는 취소입니다.
실제 핀에는 10 unit 격자보다 우선하여 정확히 붙습니다. 가운데 버튼 또는 Pan
도구로 이동할 수 있으며 편집 중 화면 범위는 자동으로 흔들리지 않습니다.

회전·반전은 기존 배선을 자동으로 늘리지 않습니다. **실제 pin/wire 기하** 모드는
바뀐 핀 접촉으로 연결을 다시 검사하므로 떠 있는 핀을 수정해야 합니다.
**명시적 pin/net** 모드는 저장된 노드 이름을 사용합니다. 두 모드의 연결 의미,
교차점과 junction의 차이, 계층 가져오기 승인 절차는 그대로 유지합니다.
소자 방향은 Register JSON·프로젝트 bundle·복제·Undo/Redo에 보존됩니다.
현재 Xschem 내보내기는 기존 정규화된 기호 배치를 생성하므로 사용자 화면의
좌표·방향을 그대로 복제하는 내보내기로 간주하지 마세요.

## 재현 및 검증

```sh
npm run test:core
npm run test:layout-editor-native
npm run test:editor-drawing
npm run build
```

`test:editor-drawing`은 별도 설계 폴더·Docker 컨테이너·웹 포트를 사용합니다.
기존 사용자 엔진을 재시작하지 않고 실제 KLayout 저장, native 핀 연결,
ngspice 동작점, 화면 배치·그리기·취소·잠금·Undo, 밝은/어두운 테마를 검사합니다.
검증 기록, 화면과 동영상은 `docs/evidence/editor-drawing/`에 저장합니다.
이 기록은 네이티브 macOS 실행·Apple 공증·상용 EDA 실행을 검증하지 않습니다.

0.18.0의 `test:layout-editor-native`는 실제 KLayout 사각형 편집·레이어 변경·복사·이동,
잘못된 입력의 원자적 거부·revision 충돌·삭제/Undo/Redo·bundle·GDS/OASIS 왕복과
실제 Magic DRC를 검사합니다. 실제 UI 조작은 별도로 확인했으며
`docs/evidence/layout-editor/`에 화면과 검증 기록을 보존했습니다.
