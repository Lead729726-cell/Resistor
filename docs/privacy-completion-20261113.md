# Resistor Edu 개인정보 안내 보완 · 2026-11-13

이 문서는 소스와 공식 자료를 대조한 운영 검토 기록이다. 완결된 법률 검토, 계정별 계약 확인 또는 배포 완료를 뜻하지 않는다. 기존 공개 0.33.0 설치 파일, `production-v1` 인증 데이터·키, Gmail 권한, 서비스 계약은 변경하지 않았다.

## 이번에 확정한 범위와 구현

운영자는 개인정보를 전송하는 온라인 기능의 제공 대상을 **만 14세 이상**으로 정했다. 인증·외부 AI·리그·커뮤니티·공동 설계를 대상으로 하며, 공개 설명 열람과 기기에만 남는 계산·학습까지 금지하는 정책은 아니다. 웹페이지 열람에도 필요한 통신정보 처리는 별도다. 생년월일·신분증을 새로 수집하거나 자기 확인을 신원·법정대리인 검증으로 표현하지 않는다.

`scripts/site/product-legal-content.mjs`에 이 승인을 기록했다. 실제 제한이 배포된 버전·소스·검증은 별도 `privacyAgePolicy.enforcement`에 기록하도록 했고 현재는 `not_verified`다. 기존 0.33.0이 이미 연령 확인을 한다고 안내하지 않는다. 새 앱 제한 구현·배포 결과는 담당 작업의 증거가 있어야 갱신한다.

`scripts/site/privacy-transfers.mjs`는 Cloudflare, 소비자 Gmail, Vercel, 연결한 OpenAI API를 각각 다음 항목으로 구분한다.

- 수령인·공식 연락처, 이전 항목·목적·시기·방법과 관계 유형
- 공급자 공개 설명과 **실제 계정의 확인된 국가 목록**
- 운영자 보관 기준과 공급자 삭제·복구 조건
- 적용 가능한 법적 근거의 검토 상태, 실제 계정·계약 증거
- 이용자가 전송을 거부하는 방법과 해당 기능의 제한

해외 공급자 소개 문구나 법인 주소를 계정별 국가 증거로 복사하지 않는다. 실제 국가 목록·계약·보관·근거 증거가 없는 상태에서는 정책 항목을 일괄 `verified`로 바꾸거나 시행일만 입력해도 `--final`이 실패한다. 이 검사는 누락을 막는 완결성 검사이며 증거 내용의 진실성·법적 적정성을 자동 판정하지 않는다.

## 국외 이전을 아직 완료로 판정할 수 없는 이유

[개인정보 보호법 제28조의8](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334957)은 국외 이전의 근거와 항목·국가·시기·방법·수령인·목적·기간·거부 방법 등을 구분한다. 계약 이행에 필요한 위탁·보관에 관한 예외는 필요한 공개·통지와 실제 처리 범위를 검토해야 하며, 모든 선택 서비스를 자동으로 포괄하지 않는다.

[PIPC 2026.4 개인정보 처리방침 작성지침](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS217&mCode=D010030030&nttId=12018) 45~46쪽은 클라우드가 여러 국가로 이전하면 해당 국가들을 기재하고 재이전도 포함하도록 설명한다. 공식 첨부 PDF 185쪽을 내려받아 해당 본문을 확인했다. 따라서 ‘글로벌’, ‘미국 등’만으로 국가 확인이 완료되었다고 표시하지 않는다. 암호화된 이메일·시리얼도 운영자가 복호화할 수 있다는 이유만으로 익명정보가 되는 것은 아니다.

Cloudflare [DPA](https://www.cloudflare.com/cloudflare-customer-dpa/)·[재수탁자 목록](https://www.cloudflare.com/gdpr/subprocessors/)의 공개 존재는 실제 해당 계정에 적용되는 모든 범위가 확인되었다는 뜻이 아니다. 구체적 계정 근거가 없는 항목은 모두 `pending`으로 남겼다.

2026-11-13의 인증된 읽기 전용 조회에서 기존 `resistor-licensing` 설정이 HTTP 200으로 확인되었다. DO binding의 `jurisdiction=null`, Worker의 `placement={}`이며 로컬 Worker도 위치 힌트를 지정하지 않는다. 공개 health는 같은 `production-v1`·SQLite schema 1·DB 준비 상태를 확인했다. 이 증거는 서비스 연결과 미지정 상태의 확인이며 실제 데이터 국가를 판정하지 않는다. 00:32:40 UTC 재조회에서는 Vercel 프로젝트·배포도 HTTP 200으로 확인되었다. 현재 배포 `dpl_9YVotLE1xFjsugiKUcv1ouQoES3X`는 READY이며 `regions`와 기본 함수 지역은 `iad1`이다. 이는 함수 실행 설정의 확인으로, CDN·로그·지원 접근을 포함한 전체 국가나 보관기간의 확인이 아니다. 로그 보관 설정은 여전히 미확인이다. 계정 ID·namespace ID·환경 비밀값은 공개 문서에 복사하지 않았다.

## 실제로 완료하는 경로

1. **기존 계정 확인**: 운영자가 해당 계정의 계약·서비스 유형·실행 지역 설정을 확인하고 민감정보를 뺀 증거를 남긴다. API 403 또는 로그인 지연은 국가 확인 성공으로 바꾸지 않는다.
2. **공급자에게 확인할 질문을 특정**: 실제 이용 서비스와 계정의 저장·백업·지원 조회·재수탁 국가 전체, 계약상 역할, 파기/반환 기간과 예외를 확인한다. 소비자 Gmail에 Workspace 문서를 제시하는 답변은 불충분하다. 문의 발송은 별도 명시 지시가 있어야 하며 이 작업에서 발송하지 않았다.
3. **확인 불가능하면 범위 변경 검토**: 필요한 데이터 최소화, 해당 선택 기능의 제한 또는 국가·계약을 확인할 수 있는 서비스로의 별도 전환을 결정한다. 기존 라이선스 DB를 새 jurisdiction으로 조용히 바꾸지 않는다. 전환 시 키·권한·기기 2대 제한·미발송 큐·중복 방지·환불 기록을 보존하는 이관 설계와 검증이 먼저 필요하다.
4. **기간과 운영 일치**: 일반 문의 해결 후 1년 등 이미 승인된 기준은 그대로 두고 인증 상태, 발송 본문과 발송 상태 기록, 공동 설계, 복구본의 기산점·기간을 구분하여 승인받는다. 단순히 ‘탈퇴 시 삭제’라고 쓰기 전에 실행 가능한 수동 절차·처리 한계를 확인한다.
5. **공개 전 대조**: 확인한 국가·계약 증거와 실제 배포 상태를 registry에 반영하고 안내·거부 경로·필요한 별도 동의 범위를 검토한다. 새 동의가 필요하면 기존 내용 승인·AI 비용 승인과 합쳐 받은 것으로 처리하지 않는다.

공급자 문의에 필요한 최소 정보는 제품명, 사용 중인 서비스 종류, 기존 authority를 유지한다는 조건과 위 질문들이다. 구매자 이메일·시리얼·데이터베이스 덤프·키를 문의에 보내지 않는다. 공개 데이터센터 지도나 법인 주소만 받은 경우 추가 확인을 종료하지 않는다.

## 아동 범위와 시행일

[개인정보 보호법 제22조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398523)는 만 14세 미만의 개인정보 처리에서 동의가 필요한 경우 법정대리인 동의·확인을 요구한다. 이번 선택은 그 보호자 절차를 새로 구현하는 대신 개인정보를 전송하는 온라인 기능을 만 14세 이상으로 제공하는 것이다. 자기 확인을 법정대리인 검증으로 표시하거나 이미 받은 아동 정보를 자동 파기한 것으로 표현하지 않는다. 알려진 아동 정보의 요청은 최소한의 대상·권한 확인 후 처리 범위를 안내한다.

시행일은 아직 승인·확정하지 않았다. 2026-11-20은 사전 준비를 위한 가능한 운영 일정일 뿐 법정 자동 시행일이 아니다. PIPC 지침 83~84쪽은 변경일·시행일과 이전 문서, 중요한 변경의 비교 가능한 안내를 설명하며 모든 변경에 일률적인 7일 사전 공지를 요구하는 근거로 읽지 않았다. 국외 이전·보관·적용 상태가 미완료인 채 날짜만 되면 최종 정책으로 전환하는 로직은 없다.

## 생성과 확인

```powershell
node --test tests/product-legal-site.test.mjs
# 검토 출력만 별도 폴더로 생성. 배포하지 않는다.
$env:RESISTOR_SITE_OUTPUT='.runtime/privacy-completion-20261113/policy'
node scripts/product-legal-site.mjs
Remove-Item Env:RESISTOR_SITE_OUTPUT
```

실제 조작 없이 검사하는 항목: provider별 필수 근거 누락, 글로벌/미확정 국가 목록 거부, 회사 소재지 설명만으로 최종화 금지, 만14세 승인과 미배포 구분, 실제 날짜 검증, 기존 사이트 바이트·라우트 보존, 반복 생성 일치. 사용자 프로젝트·기존 라이선스·구매·메일은 합성 테스트에 사용하지 않는다.

현재 소스 검사: `tests/product-legal-site.test.mjs` **9/9 통과**, 두 생성 모듈 `node --check` 통과. 정책 최종 준비 상태는 **false**이고 시행일은 **null**이다. 이 검사 결과를 실제 계정 계약, 개인정보 파기 또는 새 앱 제한의 배포 검증으로 대신하지 않는다.

수동 보관 검토 도구와 미지원 삭제 범위는 [운영 점검](privacy-operations-assessment-20261113.md), 기존 처리 절차는 [수동 운영 문서](privacy-manual-operations-20261112.md)를 참고한다. 메타데이터 검토일 계산은 실제 메일함 조사·삭제 또는 전체 보관 정책의 검증이 아니다.
