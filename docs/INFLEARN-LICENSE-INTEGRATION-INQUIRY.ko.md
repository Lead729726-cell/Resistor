# 인프런 구매·환불 연동 문의 초안

상태: 2026-11-01 사용자 요청으로 문의 발송 보류. 외부 발송하지 않음.
예정 수신처: 인프런 공식 문의 채널 https://inflearn.channel.io

안녕하세요. Resistor Edu 강의를 준비하고 있는 이석형입니다.

강의 ID 345103 구매자에게 Resistor Edu 개인용 기기 2대 라이선스를 제공하려 합니다. 결제가 확인된 구매자에게 고유 시리얼을 이메일로 발급하고, 환불·취소 시 해당 사용 권한을 회수할 수 있도록 연동 방식을 문의드립니다.

1. 공식 판매자 API, 서명된 결제·환불 웹훅, 인증된 구매 내역 조회·내보내기 또는 제휴 연동이 있나요? 지원 문서와 신청 절차, 허용되는 자동화 범위를 부탁드립니다.
2. 주문·강의별 고유 ID, 결제·환불 상태, 라이선스 발급에 사용할 구매자 이메일이나 개인별 확인 토큰을 받을 수 있나요? 선물·B2B·무료 등록·부분 환불 처리 기준도 확인하고 싶습니다.
3. API가 없다면 지원되는 구매 내역 내보내기 항목과 구매자별 일회용 링크·코드 전달 기능이 있는지 알려주세요. 외부 라이선스 전달에 필요한 개인정보 처리 조건도 함께 부탁드립니다.

수강 등록 여부만으로 결제를 추정하거나 구매 정보를 임의로 수집하지 않고, 인프런이 지원하는 방식으로 구성하고 싶습니다.

확인해 주셔서 감사합니다.
