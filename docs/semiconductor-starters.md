# 미리 만들어보는 내 반도체

2026-10-02. 상단 **내 반도체**를 누르면 공정 특징, 만들고 싶은 회로의 역할,
운전 조건을 골라 실제 편집 가능한 프로젝트를 시작할 수 있습니다. 현재 source와
로컬 개발 화면에 적용됐습니다. 기존 Windows 배포 EXE는 이번 변경으로 재패키징하지 않았습니다.

## 사용 순서

1. **내 반도체 → 공정 특징 살펴보기**에서 설치 상태와 시작 설계 연결 상태를 확인합니다.
2. SKY130에서 **내 반도체의 역할**을 고르고 설계 이름을 입력합니다.
3. 기본, 저전압·고온, 빠른 코너·저온 중 하나를 선택합니다. 실제 해석 종류·전원·코너·온도·부하를 확인합니다.
4. **이 설정으로 설계 시작**을 누릅니다. 회로, 지원되는 물리 레이아웃, testbench와 시작 설정이 새 프로젝트의 revision 1에 함께 저장됩니다.
5. **생성 후 실제 해석도 실행하기**를 선택했다면 ngspice 작업이 시작됩니다. 시뮬레이션 탭에서 실제 파형과 측정값을 확인합니다.

기존 프로젝트는 보존됩니다. 같은 생성 요청을 재시도하면 command receipt로 이미
생성한 프로젝트를 반환합니다. 워크스페이스에서 다시 열기, 복제, Register bundle
내보내기·가져오기도 시작 설정을 유지합니다. 생성 뒤에는 기존 회로도 편집,
**Testbench 설정**, DRC·LVS·PEX와 3D 뷰어를 사용할 수 있습니다.

## 준비된 8개 시작 설계

| 선택 | 준비된 회로와 해석 | 초기 레이아웃 |
|---|---|---|
| 내 첫 CMOS | 공개 inv_1 인버터, well tap, transient 입력·출력·공급 전류 | 실제 물리 레이아웃 |
| 내 MOS 특성 실험 | NMOS W 0.65µm / L 0.15µm, DC I–V | 실제 물리 레이아웃 |
| 내 4:1 MUX | 전송 게이트·버퍼 20 MOS, 20ns 입력 간격, 64개 진리표 | 실제 물리 레이아웃 |
| 내 전류 기준 | NMOS 전류 미러, 기준 100µA, OP 출력 전류·비율 | 실제 물리 레이아웃 |
| 내 차동 센서 입력 | NMOS 차동쌍, 공통 모드 0.9V, 차이 10mV, OP 가지 전류 | 실제 물리 레이아웃 |
| 내 센서 증폭기 | 저항 바이어스·커플링 C 공통 소스, AC 이득·위상 | 회로도, 레이아웃 미생성 |
| 내 MOS 증폭 특성 | 저항 부하 공통 소스, DC 전달 곡선 | 회로도, 레이아웃 미생성 |
| 내 신호 필터 | 이상적 R 10kΩ / C 1pF, 목표 시정수 10ns, transient | 회로도, 레이아웃 미생성 |

이상적 RC는 공정 의존 소자가 아니므로 기본 조건만 제공합니다. 물리 레이아웃이
있더라도 새 프로젝트의 DRC·LVS·PEX는 각각 실제로 실행해 확인해야 합니다.
생성 시 기록하는 `verification: not-run`은 시작 설정의 이력입니다. 실제 성공·실패는
독립적인 Run 결과에 기록됩니다.

## 미리 저장하는 운전 조건

| 조건 | 모델 코너 | 온도 | 전원 |
|---|---|---|---|
| 기본 | TT | 27°C | 1.8V |
| 저전압·고온 | SS | 125°C | 1.62V |
| 빠른 코너·저온 | FF | −40°C | 1.8V |

각 설계의 해석 종류와 시간 설정도 서버 카탈로그에서 읽어 적용합니다. MUX는
1280ns transient이며 기본·빠른 조건은 100ps / 5fF, 저전압·고온은 50ps / 50fF입니다.
이 설정은 회로 실험의 출발점이며 모든 설계에 대한 정격·성능 보증이 아닙니다.

시작 조건은 `semiconductor_starter.initial_testbench`에 보존되고, 수정한 현재 조건은
`project.testbench`에 저장됩니다. 화면 배너는 시작 조건과 현재 조건을 구분합니다.
각 해석 manifest에는 그 작업에 실제 사용된 조건이 남습니다.

## 공개 공정 특징과 실행 범위

| 공정 카드 | 공개 공정 특징 | 현재 시작 설계 지원 |
|---|---|---|
| SkyWater SKY130 | 130nm CMOS, 1.8V core와 별도 고전압 소자 | 실제 모델·물리 어댑터 연결 |
| GF180MCU | 180nm MCU CMOS, 3.3V / 6V 소자군 | 특징 비교. 스타터 모델·PCell 어댑터 미연결 |
| IHP SG13G2 | 130nm SiGe BiCMOS, 1.2V / 3.3V CMOS와 SiGe HBT | 특징 비교. 스타터 모델·PCell 어댑터 미연결 |

기준 자료: [SKY130 공식 규칙](https://skywater-pdk.readthedocs.io/en/main/rules.html),
[GF180MCU 공개 PDK](https://github.com/google/gf180mcu-pdk),
[IHP 공개 PDK](https://github.com/IHP-GmbH/IHP-Open-PDK).
파일 설치 여부와 실제 실행 어댑터의 준비 상태는 별도로 표시합니다.
GF180·IHP는 생성 버튼이 비활성화되며 지원 공정으로 이동하는 버튼을 제공합니다.
공개 PDK와 교육·설계 시험 결과가 foundry 제조 signoff를 의미하지는 않습니다.

새 프로젝트는 로컬 worker에서 만든 뒤 기존 공동 설계 패널로 공유할 수 있습니다.
공유 프로젝트 화면에서의 새 로컬 프로젝트 생성은 제한합니다. 인터넷 배포와 유료
클라우드 생성은 기존 사용자 결정대로 보류합니다.
