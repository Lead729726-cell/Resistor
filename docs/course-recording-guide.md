# Resistor Edu — 실험으로 설명하는 촬영 진행 가이드

이 자료는 강사용이다. 학생의 예측·설명 칸을 아래 해설로 채우지 않는다.
전체 영상은 기존 12강/약 105분 계획을 유지한다. 새 기능 소개에 시간을 더 쓰기보다
세 실험의 **예측 → 조건 하나 변경 → 관찰 → 근거 → 다음 실험**을 반복한다.
학생은 `/course/`를 옆에 열고 작성한다. 강사는 실제 Edu 앱을 조작한다.

| 1. 전기가 흐르는 길 | 빈 회로에서 전원·저항·접지 경로 설명 | 선이 닫혀 있다는 것과 전압 기준은 왜 다를까? | 경로를 자기 말로 한 문장 |

## 짧은 말하기 틀

“먼저 [변수]를 바꾸면 어떻게 될지 적어보세요. 정답을 보기 전에 멈춰도 좋습니다.
현재 조건은 [전원/부품값/연결/공정/온도]입니다. 이 실험에서는 [변수 하나]만 바꿉니다.
관찰한 것은 [실제 로그·수치]입니다. [수식/모델]의 적용 조건에서 이 차이를 설명할 수 있습니다.
아직 [기생/노이즈/공정 편차 등]은 확인하지 않았습니다. 다음에는 무엇을 바꾸어 볼까요?”

## 강사용 확인 기준

- 분압: Vin=1.8 V, R1=R2=10 kΩ, 무부하 이상 저항일 때 OUT=0.9 V, I=90 µA.
  R2만 20 kΩ로 변경하면 1.2 V, 60 µA. 학생이 R1/R2 위치나 단위를 혼동했다면 해당 입력부터 묻는다.
- RC: 이상 1차 RC에서 τ=RC. 10 kΩ·1 nF=10 µs, 5 nF=50 µs.
  τ에서 약 63.2%라는 설명은 이상 step·초기 조건을 명시한다. 실제 파형의 입력 지연을 시간축에서 분리한다.
- NMOS: 실제 엔진·모델이 없으면 수치를 낭독하지 않는다. `unavailable` 화면과 필요한 설치/모델을 설명한다.
  드레인 전류와 커패시터 전류를 같다고 가정하지 않는다. 실제 커서/측정 결과를 사용한다.
- 레이아웃: 단순 돌출을 공정 시뮬레이션이라고 부르지 않는다. P&R은 배치·배선을 포함한다.
- 보고서: 입력과 revision(1점), 예측(1점), 실제 근거와 범위(1점), 이유·다음 실험(1점)을
  강사가 검토할 수 있다. 이 루브릭 자체를 자동 채점 완료·학습 효과 입증으로 표시하지 않는다.

수업 질문 지원은 설치·연결·결과 해석 범위로 정의한다. 무제한 설계 대행, 제조 승인,
유료 외부 AI 호출, Industry 사용권을 패키지 혜택으로 약속하지 않는다.
