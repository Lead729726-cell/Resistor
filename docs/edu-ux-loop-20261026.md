# Resistor Edu · 학습 UX 개발 루프 · 2026-10-26

`codex/resistor-edu`의 기존 문제 은행·규칙 채점·퍼즐·읽기 재연결 모듈을 재사용했다. 공통 계산식·단위·회로·기하·EDA 엔진 구현은 변경하지 않았다. 학생 데이터는 Industry에서 가져오지 않았다.

## 확인한 문제와 수정

1. 문제를 바꿀 때 미제출 답안이 사라짐 → 학습 저장소·문제·버전·학생/QA 용도별 임시 답안을 보존하고 다시 연다. 저장 실패는 메모리 보관으로 표시한다. 손상된 원본을 자동 덮어쓰기하지 않는다.
2. 필터와 현재 문제의 불일치 → 필터 변경 시 목록 안의 문제를 선택하고 이전/다음·현재 위치를 제공한다. 제출 후 필터에서 제외된 문제는 결과를 먼저 읽고 다음으로 이동한다.
3. 제출 기록을 열 때 새 답안이 덮어써짐 → 다른 임시 답안이 있으면 유지한다. 과거 답안·피드백은 별도 펼침 메뉴에서 읽는다. 현재 답안이 바뀌면 이전 점수를 숨긴다.
4. 힌트 사용이 독립 풀이에 포함됨 → 명시적 `study.hint`로 도움 사용을 기록한다. 반복 조회는 idempotent하며 QA와 학생 기록을 분리한다. 기록되지 않은 과거 힌트 열람은 소급 판정하지 않는다.
5. 퍼즐 읽기 오류와 변경 오류가 섞임 → 기존 읽기 전용 재연결 모듈을 적용했다. 목록 재시도는 보드·설명을 초기화하거나 실습·해석·AI 호출을 만들지 않는다. 중복 변경 요청도 막는다.
6. 연결 안내 스타일이 대시보드에 종속됨 → 공통 연결 컴포넌트가 자체 반응형 스타일을 가져오도록 정리했다.

## 사용과 재현

제품 실행은 Node 24에서 `npm run dev:edu`다. 정식 앱의 기존 시리얼 인증은 유지된다. 새 설치 파일은 기존 합의대로 상시 라이선스 서버 연결 후 공개한다.

개발용 UI 검증은 두 터미널에서 다음 명령으로 재현한다.

```powershell
npm run qa:study-ux -- --run=local
```

```powershell
npm run dev:calculators
```

브라우저에서 `http://127.0.0.1:5177/packages/ui/qa/edu-loop/index.html`을 연다. 이 화면은 실제 SelfStudy·CircuitPuzzleLab 컴포넌트와 실제 studyRpc 서비스를 독립 QA 저장소에 연결한다. 연결 실패와 저장소 차단 버튼은 QA 전용이다. 정식 앱의 인증 설정을 변경하지 않으며, 유료 AI·EDA 해석 요청은 허용하지 않는다. 기록은 `.runtime/edu-ux-<run>/workspace`에만 저장한다. 동일 run을 다시 열면 해당 QA 기록을 재사용한다.

## 실행 검증

- 수식·단위·저장·AI 캐시·서비스·기존 핵심 회귀: `npm run test:core` 363/363 통과.
- Edu/Industry 데이터·업데이트·MCP 분리: `npm run test:editions` 9/9 통과.
- TypeScript 검사 통과.
- Edu/Industry 빌드 통과. 기존 대형 번들 경고는 남아 있다. 문서 링크 279개와 소스 감사에서 오류 0개.
- Chrome에서 실제 입력·문제 이동·새로고침·학생/QA 전환·주제/복습 필터·힌트·규칙 채점·제출 기록 재열기를 조작했다.
- 1 kΩ 색 코드 답안과 4.7 kΩ E24 답안을 공통 규칙 엔진이 100점으로 판정했다. 힌트 사용 답안은 도움받음으로 기록하고 독립 난이도 조절에서 제외했다.
- 퍼즐 읽기 실패 2회 주입 후 재연결했다. 재시도 중 배치와 작성 중 설명을 유지했다. 5 V / 1 kΩ + 1 kΩ의 이상 정적 계산은 OUT 2.5 V, 전류 2.5 mA였다. 설명을 저장했다.
- 브라우저 저장소 접근을 차단해 저장 실패를 확인했다. 경고를 표시하고 문제 왕복 중 메모리 답안을 보존했다. 새로고침 후에는 마지막으로 성공한 임시 저장만 복원한다.
- 모바일 390×844에서 문서·body 너비 384 px로 가로 넘침이 없었다. 최종 공통 스타일 적용 후 같은 크기에서 다시 확인했다.

## 범위와 다음 순서

이번 루프의 실제 외부 AI 호출과 EDA 해석 실행은 0회다. 제공자 fixture 테스트를 실제 AI 품질 평가로 해석하지 않는다. 기존 DRC/LVS/PEX 실행 이력은 그대로 보존했고 이번 UI 변경의 신규 PASS로 표시하지 않았다. 임시 답안은 해당 기기의 저장소이며 기기 간 동기화는 지원하지 않는다. 사용자 교육 효과 평가는 미실시다.

다음 우선순위는 퍼즐 설명의 revision별 미제출 복원, 오답 원인별 재학습 묶음, 교수자 과제·학습 대시보드 연결이다. 큰 자동 설계 엔진을 추가하기 전에 현재 학습의 완료율·설명 정확도·소요 시간을 사용자 평가로 확인한다.
