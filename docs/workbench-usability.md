# Resistor v0.27 · 설계 시작과 결과 확인

- **새 프로젝트**의 기본값은 빈 회로도입니다. 저항·전압원·접지를 직접 배치할 수 있고,
  빈 설계를 해석하려 하면 필요한 입력을 안내합니다. 기존 프로젝트는 보존합니다.
- **열기 / Ctrl+O / ⌘O**에서 이름·cell·PDK·ID를 검색합니다. 공정 필터와 이름 순 정렬,
  50개씩 페이지 이동을 지원합니다. 설계 파일 가져오기·저장·복제도 같은 화면에 있습니다.
- 툴바의 **다음 실행**을 누르면 현재 설계의 실행 준비를 확인합니다. 회로·레이아웃,
  입력 조건, 실제 엔진·도구 진단으로 이동할 수 있습니다. 실행 요청 가능은 PASS가 아닙니다.
- 시뮬레이션을 선택하면 실행 목록, 파형과 로그가 같은 해석을 참조합니다. **이 결과의 파형**으로
  선택한 해석을 바로 엽니다. 이전 설계의 결과는 원본 값을 보존하며 현재 결과와 구분합니다.
- 같은 설계 번호여도 모델·PDK·엔진 입력이 바뀌면 이전 결과입니다. 준비 상태,
  수치의 최신성, 기능적 PASS/FAIL/미판정은 서로 다른 상태입니다.
- 프로젝트·설정 대화창에서 Tab/Shift+Tab은 창 안을 이동하며 Escape로 닫으면 실행 버튼에 초점을 돌려줍니다.
  화면 테마·스킨·단축키·회로 노드·정밀도·파일 형식·엔진 API는 보존했습니다.

`tests/ui/workbench-usability.spec.ts`는 별도 QA 프로젝트에서 실제 0.9V와 0.6V 해석으로
선택한 실행·로그·파형 일치를 검사합니다. 실제 프로젝트 검색, 페이지 이동, 좁은 화면과
키보드 초점도 검사합니다. `tests/run-status.test.ts`는 미실행·미판정·FAIL을 PASS로
바꾸지 않고 설계 번호와 엔진 입력 변경을 구분합니다. 실행 기록은
`docs/evidence/workbench-usability/verification.json`에서 확인하세요.

## 회로도 찾기와 작업 공간 (2026-10-25)

Resistor Indust에서 검증한 공통 편집기 개선입니다. Edu와 수식·좌표·엔진 API를 나누지 않습니다.

- 회로도 캔버스에서 **Ctrl/⌘+F** 또는 **찾기**를 눌러 현재 셀의 소자 이름·ID·모델·핀/net 표기를 검색합니다. **↑↓**로 결과를 고르고 **Enter**로 선택·화면 이동, **Esc**로 닫습니다.
- 검색 종류를 **넷**으로 바꾸면 같은 net 이름을 표기한 소자·배선·접점을 함께 선택합니다. 이름 검색은 실제 전기적 연결 검사를 대신하지 않습니다. 하위 셀의 항목은 그 셀을 열어 검색하세요. 결과는 처음 40개를 표시하며 전체 일치 개수도 안내합니다.
- **Shift+F / 선택 맞춤**은 선택한 혼합 항목의 실제 회로도 범위에 맞춥니다. **F / Fit**으로 전체 회로로 돌아옵니다. 레이아웃 좌표나 회로 노드를 수정하지 않습니다.
- 배선 초안·드래그·저장 중에는 찾기로 선택 위치를 바꿀 수 없습니다. 검색어와 초안은 유지됩니다. 읽기 전용에서도 찾기·화면 이동 단축키는 사용 가능합니다.
- 낮은 창에서는 도구 영역을 따로 스크롤하고 캔버스의 최소 높이를 확보합니다. 결과 패널은 공간에 맞게 줄어들며 상단 버튼으로 접을 수 있습니다.
- 좁은 화면에서는 탐색기·속성 패널을 하나씩 엽니다. 닫기 버튼·Esc·배경 클릭으로 닫으며, 데스크톱 패널 선택과 미적용 속성 입력을 유지합니다.

실제 로컬 QA는 별도 작업 공간과 임시 QA 인증서로 수행했습니다. 고객 프로젝트·운영 라이선스·설계 엔진 결과를 만들거나 변경하지 않았습니다. 회로도 검색·보기 검증은 제조 signoff가 아닙니다. [검증 기록](evidence/schematic-usability-20261025/verification.json), [데스크톱 화면](evidence/schematic-usability-20261025/finder-desktop.jpg), [모바일 화면](evidence/schematic-usability-20261025/finder-mobile.jpg)을 확인하세요.

회귀 정의: `tests/ui/schematic-finder.spec.ts`. 이 작업의 브라우저 확인은 CUA로 실제 조작했으며, Playwright 테스트 러너 실행 여부는 검증 JSON에 별도로 기록합니다.

## 편의성 개선 루프 3회 (2026-10-26)

Resistor Indust의 세 차례 개선을 현재 작업에서 완료했습니다. 예약 자동 실행은 만들지 않았으며, 서버·설치판 배포 보류는 유지합니다.

1. **반복 검색**: 정확한 소자 이름·ID·net 이름을 접두어 일치보다 먼저 표시합니다. 회로도 편집 세션에서 셀마다 검색어·필터를 기억하며, **지우기**로 초기화합니다. 앱/편집기를 다시 시작하면 검색 상태는 초기화됩니다.
2. **레이아웃 탐색**: **Shift+F / 선택 맞춤**으로 현재 로드된 선택 도형을 확대합니다. **F / 맞춤**은 전체 범위로 돌아갑니다. 2D·3D와 복수 선택을 지원하며, DBU 정수와 설계 revision을 바꾸지 않습니다. CPU 읽기 전용 뷰에도 같은 맞춤 조작과 편집 키 차단을 추가했습니다. CPU 경로는 타입 검사·공통 정수 범위 검사를 했으며 실제 GPU 미지원 환경 조작은 미검증입니다.
3. **입력 보호**: 다른 소자·셀을 선택해도 소자별 미적용 속성 입력을 메모리에 유지합니다. 프로젝트·셀·소자 식별자로 구분하며 디스크에 자동 저장하지 않습니다. 앱을 닫으면 사라집니다. **현재 설계 값 새로 읽기**는 입력을 보존한 채 원본을 조회합니다. 같은 항목이 바뀌었다면 적용을 차단하고 원본·현재·입력을 비교합니다. 관련 없는 최신 서버 값은 보존합니다. **서버 값으로 되돌리기**는 해당 소자의 임시 입력을 지웁니다.

핵심 검사 304개와 빌드가 통과했습니다. 실제 브라우저 검증은 별도 native worker와 QA 인증서를 사용해 수행했습니다. 충돌 재현과 정상 적용 확인을 위해 QA 소자 값만 네 번 변경하고 마지막에 1000 Ω로 복원했으며, 시뮬레이션 job은 만들지 않았습니다. 새 제조 검증 결과나 installer 공개를 의미하지 않습니다.
