# Resistor v0.27 · 설계 시작과 결과 확인

- **새 프로젝트**의 기본값은 빈 회로도입니다. 저항·전압원·접지를 직접 배치할 수 있고,
  빈 설계를 해석하려 하면 필요한 입력을 안내합니다. 기존 프로젝트는 보존합니다.
- **열기 / Ctrl+O / ⌘O**에서 이름·cell·PDK·ID를 검색합니다. 공정 필터와 이름 순 정렬,
  50개씩 페이지 이동을 지원합니다. 설계 파일 가져오기·저장·복제도 같은 화면에 있습니다.
- 툴바의 **다음 실행**을 누르면 현재 설계의 실행 준비를 확인합니다. 회로·레이아웃,
  입력 조건, 실제 엔진·도구 진단으로 이동할 수 있습니다. 실행 요청 가능은 PASS가 아닙니다.
- 실행 목록, 파형 선택, 로그 선택은 같은 실행을 참조합니다. **이 결과의 파형**으로
  선택한 해석을 바로 엽니다. 이전 설계의 결과는 원본 값을 보존하며 현재 결과와 구분합니다.
- 같은 설계 번호여도 모델·PDK·엔진 입력이 바뀌면 이전 결과입니다. 준비 상태,
  수치의 최신성, 기능적 PASS/FAIL/미판정은 서로 다른 상태입니다.
- 대화창에서 Tab/Shift+Tab은 창 안을 이동하며 Escape로 닫으면 실행 버튼에 초점을 돌려줍니다.
  화면 테마·스킨·단축키·회로 노드·정밀도·파일 형식·엔진 API는 보존했습니다.

`tests/ui/workbench-usability.spec.ts`는 별도 QA 프로젝트에서 실제 0.9V와 0.6V 해석으로
선택한 실행·로그·파형 일치를 검사합니다. 실제 프로젝트 검색, 페이지 이동, 좁은 화면과
키보드 초점도 검사합니다. `tests/run-status.test.ts`는 미실행·미판정·FAIL을 PASS로
바꾸지 않고 설계 번호와 엔진 입력 변경을 구분합니다. 실행 기록은
`docs/evidence/workbench-usability/verification.json`에서 확인하세요.
