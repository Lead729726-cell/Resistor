# 설계 검토 · v0.7

설계 화면 또는 독립 뷰어에서 **설계 검토**를 엽니다.
이 화면은 현재 로드된 scene과 실제 전달받은 결과를 사용합니다.
로컬 GDS 검토에는 Docker·로그인·RPC가 필요하지 않습니다.

## 검색과 거리

도형 ID·net·cell·layer를 검색하고 결과를 선택하면 같은 도형으로 이동합니다.
검색은 로드된 도형을 대상으로 하며 최대 100개의 결과를 보여줍니다.
전체·ROI·부분 응답과 로드된 도형 수가 화면에 표시됩니다.

거리 탭에서 두 점의 정수 DBU 좌표를 입력하거나 선택 도형의 실제 꼭짓점을
사용합니다. dx/dy·Manhattan 거리와 µm 환산을 확인할 수 있습니다.
정수로 표현할 수 있는 Euclidean 거리는 정확한 값을 보여주며,
그 밖의 값은 근삿값임을 표시합니다. 이 측정은 파운드리 spacing 룰 판정이 아닙니다.

## 북마크와 비교

선택 도형 또는 점에 이름을 붙여 북마크를 저장합니다. 브라우저 저장과 JSON
내보내기/가져오기를 지원합니다. 프로젝트·revision·로드 범위와 도형 fingerprint가
달라지면 북마크를 적용하지 않습니다. 북마크는 최대 128개입니다.

현재 Scene을 기준 파일로 저장하고 다른 검토 시점의 Scene과 비교합니다.
정수 도형과 net/cell metadata의 추가·삭제·변경을 표시합니다.
부분 응답끼리의 비교는 현재 로드된 범위에 한정됩니다. 파일의 fingerprint가
내용과 맞지 않으면 변조되거나 잘못 만든 기준 파일로 판단해 거부합니다.

## 전류·파형 CSV

실제 결과가 로드된 상태에서 CSV 탭을 사용합니다. 원래의 음수·0·양수와
축·단위·source·run·project·revision·freshness를 함께 내보냅니다.
오래된 결과를 내보내도 STALE 정보가 남습니다. 전류의 수치 내보내기는
미검증 물리 경로를 검증된 벡터로 바꾸지 않습니다.

최대 250,000행을 내보냅니다. 큰 결과는 시작/끝 sample과 간격을 명시합니다.
비유한 값·누락 sample·sample 수 불일치는 거부합니다. 문자열 metadata의
스프레드시트 수식 시작 문자를 처리하며, 음수 숫자 자체는 그대로 유지합니다.

검사와 실제 화면 증거: `docs/evidence/viewer-review.json`,
`docs/evidence/native-database-ui.json`, `docs/evidence/ui-tests.json`.
