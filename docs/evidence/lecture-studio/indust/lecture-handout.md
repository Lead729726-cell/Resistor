# 첫 강의 · RC 회로와 실제 신호

Resistor Indust · 강사용 진행안 · 목표 10분

필요한 도구: 기본 ngspice · PDK 없이 실행 가능

## 1. 회로의 목적과 연결 (2분)

조작: 새 RC 데모를 만들고 IN → R1 → OUT, C1 → VGND 연결을 가리킵니다.

설명: 입력의 빠른 변화가 저항과 커패시터를 거쳐 어떻게 완만해지는지 보겠습니다. 핀과 노드 이름을 먼저 읽어 주세요. IN의 자극과 VGND 기준은 템플릿의 해석 설정으로 연결됩니다.

관찰·한계: 화면의 실제 R·C·단위와 해석 조건을 읽습니다. 아직 실행 결과는 없습니다.

## 2. 조건과 시간 상수 (2분)

조작: R1·C1 값을 선택해 읽고, 입력·클록 조건에서 펄스와 transient 구간을 확인합니다.

설명: 시간 상수는 τ=RC입니다. 현재 소자 값으로 직접 계산합니다. pulse 폭과 관찰 구간이 충분한지도 확인합니다.

관찰·한계: 수식의 예상값과 실제 해석의 조건을 구분합니다. 값 변경은 변경 적용 후 저장합니다.

## 3. 실제 해석 실행 (2분)

조작: Simulate를 누릅니다. queued/running/completed 또는 실패 원인을 실제 로그에서 확인합니다.

설명: 화면을 시뮬레이션 탭으로 바꾸는 것만으로 해석이 실행되지는 않습니다. 도구가 없으면 설치·연결 원인을 보여 줍니다.

관찰·한계: 프로젝트·revision·ngspice 출처·freshness를 확인합니다. 수치 해석 completed가 기능 PASS를 뜻하지는 않습니다.

## 4. 전압·전류·전압강하 (3분)

조작: 파형 Lab에서 IN·OUT을 비교하고, 전류/전압강하의 단자와 부호를 읽습니다.

설명: 어느 두 노드의 전압 차인지, 전류의 기준 방향이 무엇인지 설명합니다. R이나 C를 바꾸면 이전 결과가 오래된 결과가 되는 것도 보여 주세요.

관찰·한계: 저장된 실제 파형만 읽습니다. 소자 단자 전류와 금속의 공간 전류 밀도는 다릅니다.

## 5. 복습과 재현 자료 (1분)

조작: 조건·프로젝트·결과를 저장하고 강의 자료와 챕터 기록을 내려받습니다.

설명: 수강생은 자신의 환경에서 같은 조건으로 다시 실행합니다. τ를 두 배로 만들려면 R과 C 중 무엇을 바꿀지 과제로 남깁니다.

관찰·한계: 강의 진행 기록은 엔진 검증·제조 승인과 별도입니다.

## 녹화 설정

- OBS: 캔버스/출력 1920×1080, 30fps, 창 캡처로 Resistor만 선택. 실제 소스 크기에 맞춰 화면 비율을 확인합니다.
- 브라우저 녹화: 화면과 선택한 마이크를 권한 창에서 승인한 뒤 시작합니다. 실제 해상도와 fps는 녹화 기록에서 확인합니다.
- 강사 메모를 별도 창에 열고, OBS/브라우저는 앱 창만 녹화합니다.
- 짧은 샘플을 녹화·재생해 글자·목소리·노출 영역을 확인한 뒤 본 강의를 촬영합니다.
- 녹화 파일과 챕터/세션 기록은 각각 내려받아 보관합니다. 페이지를 닫거나 새로고침하면 저장 전 영상이 사라집니다.

강의 단계 이동과 학습 완료는 실제 엔진 실행, DRC/LVS/PEX PASS 또는 제조 승인이 아닙니다.
