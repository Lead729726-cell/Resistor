# 직접 강의를 찍는 강의 스튜디오

Resistor Indust와 Resistor Edu의 공통 작업 화면에서 **강의 스튜디오**를 엽니다.
`Ctrl+Shift+F9` / Mac `⌘+Shift+F9`로도 열 수 있습니다. 계산기 홈에서는 EDA 작업 화면으로 들어갑니다.
현재 소스에 추가한 기능이며, 기존 공개 v0.27.0 설치 파일에 포함되었다는 뜻은 아닙니다.

## 첫 촬영

1. 분압기, RC, 레이아웃, CMOS 인버터, 링·정전용량 센서·비트 검출·버스트 발진기 중 진행안을 선택합니다. 분압기·RC는 공개 PDK 없이 기본 ngspice로 실행할 수 있습니다. 분압기 새 데모는 빈 회로로 시작합니다.
2. **새 강의 데모 만들기**로 별도 프로젝트를 만듭니다. 기존 설계와 실행 기록을 덮어쓰지 않습니다. 현재 프로젝트로 바로 강의할 수도 있습니다.
3. **내 강의 메모**를 작성하고 **별도 강사 메모 창**을 엽니다. 진행안에는 조작, 설명 예문, 관찰점과 한계가 있습니다. 단계 이동 시 별도 메모 창도 갱신됩니다.
4. **현재 프로젝트로 강의 화면 열기**를 누릅니다. **F8**로 탐색·속성·하단 로그를 접었다 펴고 **강의용 글자 크게**로 편집기 도구·좌표·결과 표를 조절합니다. 회로 자체 확대는 편집기의 확대/Fit을 사용합니다.
5. 강의 진행 바의 **다음 →**로 화면과 대본을 넘깁니다. 실제 해석은 **Simulate**로 직접 실행합니다. 실행 조건은 해석 설정에서 읽고 오류가 있으면 실제 로그로 설명합니다.
6. 10초 정도 먼저 녹화·재생해 글자, 목소리, 노출 영역을 확인한 뒤 본 촬영을 합니다. 별도 강사 메모 창은 캡처에서 제외합니다.
7. 영상을 내려받고 **프로젝트·엔진·녹화 기록**, **실제 녹화 챕터**, **대본·진행안 저장**을 함께 보관합니다.

진행안은 RC 10분, 레이아웃 12분, 인버터 15분의 목표 시간입니다. 실제 촬영 길이를 강제하거나
완료하지 않은 조작을 실행한 것으로 기록하지 않습니다. 회로 값·공식·엔진·검증 판정은 원본 로직을 사용합니다.
네 발진기 진행안과 분압기도 별도 프로젝트를 만들며 자동 해석을 실행하지 않습니다.
[인프런 강사용 패키지 준비 도구](instructor-course.md)는 로컬 대본·수강생 실습·촬영 진행 화면을 분리합니다.

## Windows / M1 Mac / Linux 데스크톱 앱

앱의 강의 화면과 강사 메모를 사용하면서 OBS의 **창 캡처**로 Resistor 창만 녹화합니다.
OBS 캔버스와 출력을 **1920×1080, 30fps**로 맞추고 창을 화면에 맞춥니다.
마이크 입력을 선택하고 테스트 파일을 재생합니다. MKV로 녹화한 후 OBS의 remux로 MP4를 만들 수 있습니다.
macOS는 운영체제의 화면 기록·마이크 권한도 확인합니다.

앱 내부의 Electron 화면 캡처 선택기는 이번 변경에 추가하지 않았습니다. 데스크톱에서는
내장 녹화 버튼 대신 OBS 안내가 표시됩니다. 실제 Mac/Linux의 OBS·마이크 하드웨어 촬영은 별도 확인이 필요합니다.

## 브라우저 내장 녹화

화면 캡처 API를 지원하는 HTTPS 또는 localhost 브라우저에서 사용할 수 있습니다.
**화면 선택 후 녹화 시작**을 누른 사람이 권한 창에서 화면을 직접 선택합니다.
마이크는 기본 꺼짐이며, **내 마이크 포함**을 선택한 경우에만 별도 권한을 요청합니다.
시스템·탭 소리는 요청하지 않습니다. 마이크 승인을 거부하면 화면 스트림도 종료하고 녹화를 시작하지 않습니다.

1080p·30fps는 요청값입니다. 실제 선택 화면의 해상도·fps를 저장하고 표시합니다.
선택한 원본이 작으면 1080p로 촬영했다고 표시하지 않습니다.
브라우저가 지원하는 코덱을 선택하며 WebM 또는 MP4를 내려받습니다. 내장 편집·음성 합성·자동 자막·유튜브 업로드는 포함하지 않습니다.
MP4 변환이나 편집은 보관한 원본으로 별도 진행합니다.

녹화 중 **녹화 종료** 또는 브라우저의 화면 공유 종료로 마무리합니다.
30분 또는 약 512MiB에 도달하면 자동 종료합니다. 끝난 영상이 있는 동안 새 녹화로 덮어쓸 수 없습니다.
**영상 내려받기** 후 명시적으로 **내려받은 영상 비우기**를 눌러 다음 take를 시작합니다.
내려받기 버튼은 브라우저 다운로드를 시작합니다. 파일이 실제 저장되었고 재생되는지는 사용자가 확인해야 합니다.

녹화 데이터는 이 창 메모리에만 있고 서버로 업로드하지 않습니다. 새로고침·종료 전에 저장합니다.
브라우저의 종료 경고는 지원 여부에 따라 표시되며 강제 종료·충돌 시 복구를 보장하지 않습니다.
512MiB/30분보다 긴 강의는 OBS의 파일 기반 녹화를 사용하세요.

## 자료와 결과의 구분

- 대본 Markdown: 강의 목적·단계·조작·설명·개인 메모·OBS/브라우저 설정.
- 세션 JSON: edition, 현재 프로젝트 ID/revision, 실제 실행의 상태·판정·freshness, 녹화 설정·길이·종료 원인, 챕터.
- 챕터 TXT: 내장 녹화 시작 기준의 단계 이동 시각. 길이는 recorder의 wall clock이며 편집한 영상의 타임코드는 다시 맞춥니다.
- 별도 메모 창: 개인 메모를 text로만 렌더링하며 코드로 실행하지 않습니다. 모니터 전체를 찍으면 이 창도 노출될 수 있으므로 앱 창만 선택합니다.

강의 단계 이동·진행안은 엔진 검증 판정이 아닙니다. 미실행 해석·DRC/LVS/PEX를 PASS로 바꾸지 않습니다.
표시용 3D stack, 소자 단자 전류, 실제 공정 coverage·공간 전류 밀도의 차이도 진행안에서 설명합니다.
계정·유료 AI 호출·외부 업로드 없이 촬영 준비를 할 수 있습니다. Edu/Indust 메모와 진행안 선택은 edition별로 저장합니다.

[Indust 실제 UI 검사](evidence/lecture-studio/indust/ui-verification.json)와
[Edu 실제 UI 검사](evidence/lecture-studio/edu/ui-verification.json)는 격리된 실제 native 프로젝트,
원본 보존, 단계 이동, 단축키, 별도 메모 창, 테마·모바일 화면과 다운로드를 확인합니다.
각 디렉터리의 `actual-app-workflow.webm`은 실제 앱 조작 녹화입니다.
`recorder-fixture.webm`은 명시적인 canvas 테스트 소스입니다. 실제 MediaRecorder bytes·재생·트랙 해제를 검증하지만
운영체제의 화면 선택 창·실제 마이크·OBS 촬영 성공을 입증하지 않습니다. 유료 호출은 하지 않습니다.

구현은 [getDisplayMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)와
[MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)의 권한·지원 코덱 동작을 따릅니다.
