# Resistor Edu 개발 루프 3회

Edition: `edu` / Resistor Edu. 인프런 판매 예정가 250,000원, 자체 결제 보류,
기존 키·시리얼 및 Industry 데이터는 유지한다.

## 1회차 — 학습 기록 보호

발견: 가져오기에서 이전 후보가 남을 수 있었고, 다른 탭의 새 기록·손상된 원본·저장 실패를
고려하지 않은 전환이 학생의 설명을 덮어쓸 수 있었다.

수정: 가져오기 후보의 즉시 초기화와 비동기 순서 검사, 원본과 현재 작성 내용의
검증된 백업 후 전환, 탭별 임시 기록과 충돌 감지, 실패 시 입력 유지·저장 재시도를 추가했다.
유효한 JSON의 속성 순서만 달라진 경우는 허용하되 결과 변조는 계속 거부한다.
워크북 스크립트도 타입 검사 범위에 포함했다. 기존 v1 데이터·과정 revision은 유지한다.

확인: 학습 기록·저장소 회귀 테스트 10개, 사이트 재생성, 타입 검사 통과.
손상된 원본은 바이트 그대로 보관되며 저장 실패 후 재시도로 덮어쓰지 않는다.

## 2회차 — 조건을 통제하고 결과 설명하기

발견: SI 수치와 영어 결과명이 입문자에게 읽기 어려웠고, 입력을 여러 개 바꾼 경우도
단일 변수 실험처럼 보일 수 있었다. 같은 계산 버튼을 반복해 기록이 불필요하게 늘어났다.

수정: 한국어 결과명과 공학 단위, 같은 단위의 전후 비교, 추천 변수 하나 변경,
단일/복수 변수 구분과 관찰→모델→근거→다음 실험 안내를 추가했다.
저장한 결과만 설명하며 AI 호출이나 학생 설명의 자동 작성은 하지 않는다.
revision뿐 아니라 실행 입력도 비교해 현재 결과 여부를 판단한다.
중복 실행 기록과 비유한·정밀도 범위 밖 수치의 새 기록을 차단하고 이전 기록은 유지한다.
계산식은 기존 공통 계산기를 재사용한다.

확인: 워크북·저장소·실험 회귀 테스트 16개, 사이트 재생성, 타입 검사 통과.
