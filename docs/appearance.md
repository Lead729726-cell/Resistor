# 레지스터 화면 스타일과 로고

v0.9.0에서는 회로 배선과 셀 경계를 담은 **R 심볼**을 로고로 사용합니다.
설계 작업 화면, 독립 GDS 뷰어, 브라우저 아이콘 및 Windows 실행 파일에 적용했습니다.

화면 오른쪽 위의 **스타일** 버튼을 눌러 색상 모드와 스킨을 선택하세요.
선택한 스타일은 즉시 적용되고 현재 브라우저 또는 Windows 앱 프로필에 자동 저장됩니다.

| 색상 모드 | 동작 |
| --- | --- |
| 라이트 | 밝은 작업 화면을 유지합니다. |
| 다크 | 어두운 작업 화면을 유지합니다. |
| 시스템 | 운영체제의 밝은/어두운 모드를 따르며 변경 시 바로 반영합니다. |

| 스킨 | 색감 |
| --- | --- |
| 그래파이트 | 차분한 슬레이트와 선명한 블루 |
| 제이드 | 깊은 그린과 부드러운 민트 |
| 코퍼 | 따뜻한 뉴트럴과 구릿빛 포인트 |
| 아이리스 | 바이올렛과 은은한 라일락 |

스킨마다 라이트·다크 화면을 제공하므로 총 **8개 색상 조합**을 사용할 수 있습니다.
작업 패널, 입력창, 회로도, 레이아웃 도구, 2D/3D 배경, 파형, PDK·상용 Backend·파일
호환·원본 DB·설계 검토·통합 설계 설정에 같은 스타일이 적용됩니다.
PDK에서 정한 레이어 색은 설계의 의미를 유지하며, 화면 스타일 전환으로 변경되지 않습니다.
열어 둔 설계의 도형, 해석 결과, revision 및 카메라도 유지됩니다.

같은 브라우저에서 같은 주소를 연 탭은 스타일 변경을 함께 반영합니다.
기기나 브라우저 프로필마다 스타일을 따로 선택할 수 있습니다.
기존 버전에서 저장한 라이트·다크 선택도 이어받습니다.

키보드로도 설정할 수 있습니다. 모드/스킨 그룹 안에서 방향키로 이동하고,
Home/End로 처음/마지막 항목을 선택합니다. Esc를 누르면 창이 닫히고
스타일 버튼으로 포커스가 돌아옵니다. 작은 창에서는 설정 창 안을 스크롤합니다.

로고 원본은 [register-symbol.svg](../public/register-symbol.svg), Windows 아이콘은
[register.ico](../apps/desktop/assets/register.ico)입니다. 16~256px의 7개 크기를
ICO에 포함합니다. 화면의 심볼은 스킨에 맞는 색으로 표시합니다.

디자인 토큰은 `packages/ui/src/appearance-presets.json`에서 관리합니다.
`npm run build`는 테마 CSS와 첫 화면 설정 복원 스크립트를 함께 생성합니다.
로고 원본을 수정했다면 `npm run brand:assets` 후 `npm run package`로
Windows 아이콘을 갱신합니다.

검증 기록은 [UI 검증](ui-verification.md), `evidence/appearance-ui.json`,
`evidence/appearance-release.json`에 있습니다. 실제 GDS 도형과 캔버스 픽셀,
주요 텍스트·버튼 대비, 설정 복원, 키보드 조작, Windows 앱 재시작 및
로컬 Linux 서버의 8개 조합을 확인했습니다.
