## 현재 공식 근거와 적용 한계

개인정보 처리방침에는 처리 목적·보유 기간·권리 행사·보호책임자 또는 담당 부서의 연락처 등
해당 항목을 정해 공개해야 한다. 따라서 문의 연락처가 존재한다고 기간·파기·이전 정보의 공백까지
해결된 것은 아니다. [개인정보 보호법 제30조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334949),
[보호책임자 지정 제31조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900079330).

거래기록 보존은 표시·광고 6개월, 계약·청약철회와 대금결제·공급 5년,
소비자 불만·분쟁 3년으로 구분된다. 철회한 소비자의 보존 대상 기록도 별도 관리 규정이 있다.
[전자상거래법 시행령 제6조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=63460).

국외 이전은 별도 동의 외에도 계약 이행에 필요한 위탁·보관에 대한 고지 등 법에서 정한
근거를 검토해야 하며, 실제 국가·항목·받는 자·기간 등을 식별해야 한다.
단순히 외부 AI 실행 체크박스가 있다는 이유로 모든 국외 이전 요건을 충족했다고 판단하지 않았다.
[개인정보 보호법 제28조의8](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334957).

Cloudflare는 기존 Durable Object의 위치 선택과 위치 힌트의 한계를 설명한다.
현재 소스는 국가 제한을 지정하지 않으므로 국가를 추정하지 않는다.
[Cloudflare 데이터 위치](https://developers.cloudflare.com/durable-objects/reference/data-location/).
Google·Vercel은 글로벌 정보 처리 안내를 제공하지만 그것만으로 이 계정의 구체 계약을 확인한 것은 아니다.
[Google 개인정보 안내](https://policies.google.com/privacy?hl=ko),
[Vercel 개인정보 안내](https://vercel.com/legal/privacy-notice).

API 응답 저장 설정과 악용 감시 보관은 서로 다르다. 일반적인 API 악용 감시 30일 안내와
계정·안전 관련 예외를 확인했으며, `store:false`를 무조건적인 무보관 보장으로 사용하지 않았다.
[OpenAI API 데이터 처리](https://developers.openai.com/api/docs/guides/your-data).
